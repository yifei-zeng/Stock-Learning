# 我的交易系统 · 中短线版（七组件）

> 方法来源：认知税系列（逻辑哥复盘笔记，12篇）+ 情绪节点寻龙（来去由心，短线龙头战法）
> 核心区分：**策略回答"买什么"，系统回答"每一步先做什么"。**
> 状态：**初稿 v2（Agent 预填，待主人确认）。填完只是开始，跑完 20 笔再验收。**
> 原则：少即是多——每个组件写 2~3 条，总共二三十条足够记住；写多了你会选择性执行。
> ⚠️ 打 `【待你填】` 的只有你自己知道、我不替你编；其余默认值均为方法论提炼，可按资金体量重校准。

---

## 决策链总览（每一步先做什么）

```
开盘前30秒：今天触发条件是什么 → 仓位上限是多少 → 什么情况不做
      ↓
盘中：只在计划内的触发点上动手；止损止盈挂条件单，不靠意志力
      ↓
收盘后15分钟：五段式复盘 + 龙头节点跟踪8问 + 错误三分法
      ↓
每周/每月：周复盘四步 → 每月至少改出一条规则
```

## 组件 1：定位

| 项目 | 我的答案 |
|---|---|
| 我的资金属性（能放多久、会不会临时动用） | 【待你填】建议：至少 1 年内不动用、与生活开销隔离 |
| 每天能用于盯盘的时间 | 【待你填】中短线**只需收盘后15分钟复盘**；若不能全程盯盘 → 排除纯接力/打板，只用启动突破+高低切+节点寻龙的换手/卡位买点 |
| 能连续扛亏几次 | 【待你填】先写死：默认**连亏3次**→停手复盘 |
| 我的性格 | 【待你填】 |
| 我选择的打法 | **中短线（3~15个交易日）** = 短线择时 + 波段纪律 |

> 定位错误是最大的坑："白天上班只能晚上看账户，却选了一套全天盯盘的超短线打法"——**这不是纪律问题，是定位问题。**
> 中短线的分工：**情绪周期负责"赚多少"，仓位止损负责"亏多少"，两者分开，别混。**

## 组件 2：标的池（先排雷，再看方向）

**入池四条件（同时满足）：**
1. **方向**：主线②发酵期——龙头 + 梯队(5-4-3-2-1) + 连续2~3天活跃，三信号齐
2. **身份**：节点梯队里的大单一字票（**一字龙**）+ 该换手就老实换手的票（**半身/换手龙**）
3. **股性**：换手/成交额有下限，股性活跃——"无股性无情绪无资金无催化，不要聊"
4. **排雷通过**：审计无保留 + 净现比≥1 + 应收/存货增速≤营收 + 无大存大贷 + 商誉占比低 + 流动比率≥1

**剔出条件**：主线退潮、财报暴雷、跌破流动性下限、龙头炸板/卡位失败作废
**数量上限**：50~100 只（池子再大等于没有池子）

## 组件 3：买入条件（三层漏斗）

**条件 1 · 方向/节点（先过）**：主线②发酵期 + 节点梯队成立（大单一字封单=能量源 + 梯队票≥8只 + 上方高度真空）
**条件 2 · 选股（三选一，可叠加量化筛股）**：
- 启动突破：日线+周线**双突破**放量突破前高/平台
- 高低切：龙头封板/高位，同板块补涨/后排放量异动
- 节点寻龙：定节点 → 定龙头 → 定半身
- 量化筛股（稳健版，可作启动突破的过滤条件）：日线/周线突破 + 日线**MACD金叉** + 放量 + 站上**20日均线**（单仓≤10%）
**条件 3 · 盘口触发（买点信号）**：
- 一字龙竞价三一、开盘拉升秒板 ｜ 换手卡一字（对手开一字走弱、我方换手封死）
- 竞价抢筹卡位 ｜ 买在分歧（节点能量在+外围利空）｜ 题材回流（对手全死）
- 量价健康：价涨**量增**（量缩=动能衰竭、滞涨=顶部，不买）

**下单前**：6问（在池内/排雷过/条件齐/止损位/最多亏多少/计划还是手痒）+ 写反向观点（我可能错在哪/什么信号证明我错/最坏亏多少）

> 检验法：把买入条件拿给完全不懂股票的人看，他看完仍不知道买不买 = 不合格。

## 组件 4：仓位规则

- **下单量**（固定分数法）：`可买股数 = 总资金 × 2% ÷ (入场价 − 止损价)` —— 先有止损位，才谈买多少
- **单笔最大亏损 ≤ 2%**；**月度累计亏损 ≤ 6%** 熔断
- **单票 ≤ 10%**、同时持仓 **≤ 3~4 只**、**现金永远留 10%~20%**
- 三层结构：底仓（跟市场）+ 机动仓（主线波段）+ 现金（选择权）
- 加仓：仅浮盈、金字塔式（每次递减、次数≤2）；禁止倒金字塔补仓
- 减仓四触发：到止损位 / 逻辑破坏 / 到目标位（第一批先减一半）/ 单票超限
- 熔断：连亏3次停手 ｜ 回撤10%停3天 ｜ 月亏6%当月停 ｜ 连三个月亏15%暂停

## 组件 5：止损规则

**触发任一即离场（按优先级）：**
1. 单笔亏损达总资金 **2%**（最高优先级）
2. 跌破近期前低 / 跌破 **MA20**（个股不做左侧抄底）
3. 固定百分比 **8%~10%**（兜底，嫌高用5%~6%）
4. 买入逻辑破坏：主线退潮/财报暴雷/**龙头炸板、卡位失败=买点作废→立即认输不硬拿**
5. 情绪止损：状态不对（极致焦虑）→清掉不碰

一天最多止损 **3 次**，超过当日停手；连亏 3 次 → 第一反应是复盘不是加仓。

---

## 组件 6：止盈规则

- **分批止盈（首选）**：仓位分3份，浮盈 **+10% / +20% / +30%** 各卖一份，先拿回本钱，让子弹飞
- **目标止盈**：到 **+20%** 就收手（新人可只设这一条）
- **情绪止盈**：情绪读数 >80 过热 / 全网都在聊 → 分批减仓
- 短线专用：**炸板减 → 回落到8个点减 → 跌破均线再减**
- 超跌反弹/事件级：赚 **2~4 个点**就够，次日冲高即走，不留恋（超跌反弹底线：**≥3 个跌停**后才接割肉盘，不接出货盘）
- 动态跟踪：涨了把止损线抬到成本线，再涨再提（10→10.2设10.1→10.5设10.3）

> 别写"赚够三千万就收手""回本了就走"——后者注定让你老在回本线附近震荡。

## 组件 7：复盘迭代

**每日（收盘后15分钟内）**：
1. 五段式复盘：指数→情绪→资金→计划→推演（顺序不能改，见 `每日复盘模板.md`）
2. 龙头节点跟踪8问：最高板是谁/上方有无空间真空 → 哪队有大单一字、封单多少亿 → 梯队≥8只吗 → 一字龙、半身是谁 → 半身该换手就换手吗、有无对手开一字作死 → 竞价谁抢筹谁被卡 → 卡位成功吗（没成→立即认输）→ 对手题材死了吗（午后回流）
3. 每笔亏损错误三分法：可避免（修纪律）/ 不可避免（不改规则）/ 系统性（改规则）

**每周**：四步周复盘（验证预判 / 主线实况 / 改哪条规则 / 下周观察）
**每月**：**至少改出一条规则**——没有产出规则 = 只在记账

> 市场会改变，你的规则不会变。复盘迭代是整套系统里唯一会进化的部分。

## 系统验证：三关全过才算能用

| 关卡 | 检验方法 | 我的状态 |
|---|---|---|
| 一致性 | 连续 20 笔，有没有一笔是规则之外的 | ☐ 未开始 |
| 期望值 | 胜率×平均盈利 − 败率×平均亏损 **> 0** | ☐ 未验证 |
| 样本足够 | 20~30 笔实盘/回测；换到单边下跌、情绪极端环境还成立吗 | ☐ 未验证 |

> 一个 60 分的系统执行 100 次，胜过 90 分的系统执行十次。
> 破例就记一笔：小红本记做得好的，小黑本当错题本。

## 一页纸铁律（贴屏幕旁）

1. 单笔 ≤2%，月度 ≤6%，单票 ≤10%，持仓 ≤4 只，现金 ≥10%
2. 只在主线②发酵期 + 节点梯队成立时动手；④退潮期空仓
3. 破前低 / 破MA20 / 卡位失败 → 立即认输，不硬拿、不聊格局
4. 分批止盈，先拿回本钱；人声鼎沸时减仓
5. 连亏3次停手复盘；每天收盘后15分钟内写完复盘
6. 不追高、不补跌、不借消息下单；破例记小黑本

## 三个常见缺陷（自查）

- [ ] 只有进场没有出场
- [ ] 规则互相冲突（如"跌破均线止损"+"回调加仓"并存）——必须先定优先级
- [ ] 规则写给理想的自己——"我有时间盯盘""我能早发现异动"，你做不到

> 规则是写给理想的你，还是写给真实的你？
