# 每日复盘模板（五段式）

> 方法来源：认知税系列第七篇（BV1XTh76JEmQ）
> 核心原则：**复盘不是回忆，是审判。审判的对象不是市场，是你所有的决策过程。**

## 使用规则（先读这三条）

1. **收盘后 15 分钟内写完**，别拖到晚上，更别隔一周。一周后再回看，你会给自己编故事。
2. **五段顺序不能改**：先客观（市场事实）后主观（你的计划）。先写计划再看市场 = 自我安慰。
3. **每段 3~5 句就够**，不必写四五千字。**没有产出规则，你还是在记账。**

## 今日复盘 · ____年____月____日

### 第一段：指数（只写事实，禁止出现"我觉得"）

- 成交额：______（较昨日 放量 / 缩量 ______）
- 主要指数：上证 ______ 深成 ______ 创业板 ______；涨跌家数比 ______
- 涨停 ______ 家 / 跌停 ______ 家
- 资金：机构 ______ 主力 ______ 散户 ______
- 关键支撑位 ______ 压力位 ______
- 盘面特征：V 型反转 / 高举高打 / 低开高走 / 缩量震荡 / 其他：______

### 第二段：短线情绪（好不好赚钱 ≠ 指数涨跌）

- 涨停家数较昨日：______；最高连板高度 ______
- 炸板率：______%（例：10 个封板炸 3 个 = 30%）
- 昨日强势方向今日表现：延续 / 切换 / 轮动 / 退潮
- **量能开关**：今天放量还是缩量？→ 决定龙头断板算"温和断板"还是"核按退潮"（来去由心11·稿 21:16–21:47）
- **盘中 3 分钟判题材分歧**：三个封标核心票一起走弱 = 分歧偏大；只一两个走弱 = 题材还扛得住（来去由心11·稿 19:32–20:01）
- 一句话定调：今天好做还是不好做？______

### 第三段：主线资金（钱往哪儿流，不是今天买什么）

- 当日资金流向：______；5 日资金流向：______
- 主线有无新方向：______
- 活跃资金：流入 / 流出 / 内部切换；强度：变强 / 变弱
- **我的持仓在不在主线上？** 在 / 不在
  - 不在的话：为什么不在？下次怎么把握？______

### 第四段：明日计划（必须带触发条件）

**先填三档预案**（来去由心12·稿 10:57–11:22，竞价如开奖、按预案执行，**不临时想**）：

| 档位 | 竞价/早盘长什么样 | 我做什么 |
|---|---|---|
| **走好** | ______ | ______ |
| **走平** | ______ | ______ |
| **走差** | ______ | ______ |

再填具体计划：

- 观察方向：______
- 触发条件：**如果 ______ 成立，我才做 ______**
- **这是第一买点还是替补买点？**（第一买点没出现就不做，不用第二买点替补 —— 来去由心11·稿 06:11–06:36）
- **我要买的这只在同题材里排第几？**（龙三龙四不买 —— 来去由心12·稿 08:06–08:30）
- **新模式的赔率够不够？**（对了能赚几个点 —— 来去由心11·稿 03:56–04:19）
- 仓位上限（按我的仓位规则算）：______
- **明确写出什么情况下我不做**：______

### 第五段：情景推演（至少三个）

| 情景 | 假设 | 我的动作 |
|---|---|---|
| **强** | 主线延续 + 量能放大 | 按计划执行，仓位不超上限 |
| **窄幅** | 主线不明朗 | 减半 或 观望 |
| **主线破坏** | 情绪转弱 | 不执行，先减仓等信号 |

## 收尾：本次复盘产出了什么规则？

> 判断复盘有没有进化，只看这一条：**一个月下来有没有修正过一条规则。**

- [ ] 今天有没有产出 / 修正一条规则？
- 新规则 / 修正内容：______
- [ ] **今天的盘前三档预案，实际落在哪一档？我按预案执行了吗？** 没按预案走的，原因是什么？（这是验证"计划你的操作"有没有落地的唯一方式）
- [ ] **动态板块刷新了吗？**（连板梯队/反包/断板/炸板 —— 不刷新第二天不出票，来去由心10·稿 26:16–28:28）

## 亏损归因：错误三分法（不是每笔亏损都该你背锅）

| 类型 | 定义 | 处理 |
|---|---|---|
| **可避免** | 违反了你自己写的规则（明知道止损了还在扛） | 修纪律，没得洗 |
| **不可避免** | 规则内正常执行，遇到系统性下跌崩了 | **不用改，这锅不在你身上** |
| **系统性** | 规则/策略本身期望值不行、止损位设置有缺陷 | 改规则本身 |

> 最常见的坑：把"不可避免"当成"可避免"去自责——**自责久了会乱改规则，把你本来能赚钱的系统破坏掉。**

### 每笔亏损问自己四个问题

1. 有没有**提前定下计划**？亏损到底怎么来的？
2. 执行时**有没有按计划做**？（看好却没做，是因为太高还是因为害怕？）
3. **同样情况连续亏损 10 次以上 → 大概率是规则问题；十次错一次 → 规则没大毛病**
4. 同样情况下**过去 20 笔**是赚多还是亏多？（样本必须够，别拿一两个案例下结论）

## 周复盘（每周一次，管整体方向）

1. 本周验证上周的预判，对了几个？
2. 本周实况：主线走成了什么样？
3. **这一周该改哪条规则？**
4. 下周重点观察什么？

## 三条验收标准

1. **能否回看**——一个月后翻回去还记得当时发生了什么（记的是事实不是情绪）
2. **能否证伪**——**一个月的复盘至少要修正一条规则**
3. **有没有产出规则**——没有规则产出 = 还在记账
