## 核心观点

1. **"卖在最高"不是猜顶，是一套按顺序触发的卖出规则**：先减半做利润垫 → 反抽不过均线就清 → 回封再被爆头就在均线上方砸完（稿 06:57–07:20）。
2. **跌破均线≠卖点，"跌破后反抽上不去均线"才是卖点**：跌破均线只是转弱标记，要等反抽出局（稿 01:03）。
3. **减仓优先于清仓**：全片最高频动作是"卖一半/减一半"，只有确认"不过均线"或"不会封"时才清仓（稿 01:17，06:57）。
4. **第一笔减仓的目的是买"冷静"**：利润垫做出来才有发挥空间；成本高到影响判断，这个票就没法操作（稿 07:49）。
5. **环境判断优先于分时判断**：同样的炸板处理只在"中性环境"成立，退潮期可能天地板（稿 06:34）。

## 操作逻辑（选股·买点·卖点）

### 买点相关

- **关键价位不破 = B点**：如29.8不跌破就是B点，跌破需要低开急拉修复（稿 00:23）
- **左侧买的条件**：到主力成本位附近、且"主力不想做就会把它洗破"说明洗到位；还有洗盘空间就看右侧（稿 11:22）
- **左侧仓位上限 1/4 仓**（稿 08:24，11:59 语境）
- **不单从成本抄底**（稿 14:05）
- 开盘急拉很强可做正T（稿 01:38）

### 卖点触发清单（按优先级）

| # | 触发 | 动作 | 出处 |
|---|---|---|---|
| 1 | 跌破关键价位（如29.8） | 转"找高点走" | 稿 01:29 |
| 2 | 跌破分时均线 | 转弱标记，**不是卖点**，等反抽 | 稿 01:03 |
| 3 | 反抽上不了均线 | **都是出局点** | 稿 02:23 |
| 4 | 跌破前低/平台支撑 | 转弱确认，走 | 稿 02:23，13:11 |
| 5 | 不及预期的票急拉 | **拉升就是出局点**（修复太快） | 稿 03:09 |
| 6 | 尖角波下来跌破成本线 | 坚决出局（反面案例亏9个点） | 稿 02:48 |
| 7 | 涨停前有冲高回落动作 | 大概率不连板，拉升是减仓点；板了才拿剩余 | 稿 04:40 |
| 8 | 炸板后反抽 | 先减一半 | 稿 06:57 |
| 9 | 反抽不过均线 | 清仓 | 稿 06:57 |
| 10 | 回封 | 剩余仓位拿着 | 稿 06:57 |
| 11 | 回封又被爆头 + 量已爆出 + 已上去过一次 | **均线上方清仓**，不会封了 | 稿 07:10 |
| 12 | 板上能砸 | 就在板上砸，不用等更低 | 稿 08:08 |
| 13 | 溢价异常 + 开盘均线向下 + 快速下探后拉升 | 那个高点就是砸盘点 | 稿 12:35–12:43 |

### 仓位规则

- 转弱未确认 → **先卖一半**；确认才清仓（稿 01:17）
- 翘板/反核只上 **1/4 仓** 玩（稿 08:24）
- 底仓砸到极低位置时"没必要卖了"（稿 01:53）
- 1/4 仓没法做减仓动作，教学演示才用两个单位（稿 11:59 语境）

## 关键规则与数字

- 关键点位示例：**29.8**（趋势线，不破=趋势没问题）（稿 00:23）
- 支撑价位示例：**4.18 / 4.03 / 4.01**（4.01几次不破是支撑，破一次=走弱）（稿 12:13–13:11）
- 翘板时机：跌停次日**早盘2分钟**翘板可跟一笔（稿 08:24）
- 仓位数字：左侧/翘板 **1/4 仓**；减仓以"一半"为单位（稿 08:24，01:17）
- 反面教训：跌破成本线不走 → 拖到最后**亏9个点**（稿 02:48）
- 硬纪律两条：不及预期的票拉升即出局；尖角波跌破成本即出局（稿 03:09）

## 案例分析

- **29.8关键位票**：扫板介入 → 跌回箱体到主力成本附近持有 → 反抽卖一半在日内高点附近 → 29.8过不去减仓 → 尖角波出现后等高点出局 → 连续上影线该走未走成反面案例（亏9个点）（稿 00:01–02:48）。
- **1280周K突破票**：周K突破+回踩不破+阳线放量，多拿一天；涨停前有冲高回落 → 拉升减仓；次日无溢价开盘杀，因"没耐心"提前清了，自评"这个肉不该我们吃"（稿 03:48–04:53）。
- **消费刺激缩量板票（标准处理模板）**：扫板 → 次日缩量板被爆头 → 中性环境假设下等反抽 → 反抽减一半 → 不过均线清仓 → 回封拿回 → 回封又被爆头、量已爆出 → 均线上方清仓。UP主自评"非常标准的短线票处理"（稿 05:43–08:08）。
- **跌停翘板票**：次日跌停，早盘2分钟翘板跟1/4仓；彻底走弱后低开找高点走；乖离大不追杀；平台支撑不破可拿（稿 08:24–09:27）。
- **4.18低价票（"卖在最高点"演示）**：溢价仅1个点异常 → 1分K发现开盘均线向下+快速下探后拉升 → 判定高点减仓，复盘确认卖在最高点（稿 12:13–12:43）。
- **粤宏远A复盘**：涨停日在最高点减半——依据"均线跟分时不对劲+已去过最低点=这里是高点"，强调非马后炮（稿 14:37）。
