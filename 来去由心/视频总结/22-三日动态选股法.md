## 核心观点

1. **票池来源只有三个：断板、炸板、涨停**。每天这三个池子里的票全部过一遍，按"选美原则"把形态好看的挑出来（稿 00:00、00:17）。
2. **"三日"不是选股条件，是滚动机制**。当天选出的票次日再筛一遍、第三天再筛一遍，每天既补新票也删旧票，最终留下一个动态票池（稿 00:22、00:46、01:13）。
3. **方法是"必要条件"不是"充分条件"**：每天只覆盖二百多只，趋势票不全部从这里产生，要做得更好必须配合其他选股方法（稿 01:39、09:47、39:15）。
4. **选票审美无法规则化**。UP 主明确说这个东西"只能耳濡目染"，形态太多，要总结也只能抽出几个标准形态／模型（稿 39:24、39:36）。**本篇的价值是"看 UP 主怎么判"，不是拿到一张可执行清单。**
5. **否决优先于买入**。全篇 39 分钟里，"不看了""删了""太丑了""涨太高"出现的频次远高于"这是买点"——**筛选的主体动作是排除**（稿 34:23、38:51）。
6. **趋势票随缘**。不给舒服的入场点就不做，"选票就像等一个有缘人，等到了就上车，等不到就让他走"（稿 03:44、03:50）。
7. **只做锦上添花，不做雪中送炭**。需要靠每天几十亿成交去消化左侧巨量套牢盘的票，不做（稿 14:43、14:50）。

## 行情判断

### 龙头预案：用龙头走势判断当日题材修复强度（稿 13:31~13:49）

| 龙头开盘表现 | 题材当日结论 |
|---|---|
| 高开／低开急拉直接拉红（且不能开太低） | **强修复**（稿 13:02、13:16） |
| 浅水开 → 水下消化分歧 → 不往跌停走 → 拉升回调 | **弱修复**（稿 13:06、13:42） |
| 五个点以下开盘、直接奔跌停 | **题材主升至少先结束，后续走轮动**（稿 13:45） |

### 风标的量化读法（稿 12:48~12:54）

左侧资金 93 亿、当日成交 72 亿 → 至少锁住 20 多亿 → 该票是当日"非常重要的风标"，其反馈会影响整个题材走势。

### 其他盘面判断

- **题材加持是趋势票的加速器**：形态再好，没有题材加持也可以不看（稿 05:09、16:41）。
- **市场高度**：录屏当日最高四板，三进四是"三哥"〔?〕的票（拓山重工〔?〕）（稿 29:33~29:38）。
- **板块联动**：稀土板块由北方稀土带动，调整后可能跟着题材再动（稿 36:59）。
- **连续反弹两根 K 线后大概率调整**；昨天是烂板今天就要大减（稿 12:13、12:21）。

## 操作逻辑（选股·买点·卖点）

### 选股（票池构建与筛选）

- **建池**：断板／炸板／涨停三池，每天全部过一遍（稿 00:00）。
- **滚动**：当天选约十只 → 次日再筛保留三到五只 → 第三天再补新票，池子保持最近三日（稿 00:25~00:56）。
- **每日减法**：收盘后筛掉走弱、走不好看的，留下来的就是次日核心关注（稿 01:13、01:18）。
- **懒人法**：直接按"三个交易日内曾涨停"筛，约七十多只（稿 01:29、01:33）。
- **量级感**：一天看约一百只，选出十只，最终只剩十三只（稿 34:08、34:14、38:57）。

### 买点

**A. 通用模板：突破平台后回踩关键位不破（稿 27:22、27:38）**

> "你突破平台之后，回踩这个支撑不破，那可以适当关注一下；如果破了算了，如果说直接往上走了也算了。"
> "你调整、回踩之后不破，那可能看一看；破了先出局，不破那可能往上有个反弹。"

具体点位实例：荣泰健康 29.9（稿 16:36）、奥瑞德 3.76（稿 21:15）、航天动力 14.37（稿 03:29）、立顶光链〔?〕34.24（稿 28:19）、某医药股 10.9 以上〔?〕（稿 26:56）。

**B. 主力明牌上车（稿 30:09~30:46）**

烂板放量涨停（吃货）→ 次日水下**缩量整理**（筹码稳固）→ 净额亮眼 → **一个高开就很容易上车**。"稍微有点趋势基础的话，这种上车太容易了。"

**C. 尾盘埋伏（稿 32:14~32:22）**

形态已突破高点 + 尾盘净额大幅流入 → 必有资金抢筹 → 直接尾盘埋伏。

**D. 两个买点的区分（稿 33:01~33:08）**

- **埋伏买点**：放量突破后缩量整理（小 K 线）的那一天；
- **加速买点**：再一根阳线那天——复盘仔细的话，看到净额当天就要先进去，尾盘可以埋伏。

**E. 被动入场（稿 25:16~25:32）**

冲高回落那天被动进场的，次日能反包、筹码没走坏，后面还能走。但这个买点之后趋势票买点基本就没了。

**F. 主力吃货的验证式（稿 37:42~37:53）**

位置不高 + 突然放量 → **次日缩量调整且不跌** ＝ 资金很淡定 ＝ 是主力在吃货。
> ⚠️ UP 主自己加了一句："当然只是个大概率"（稿 38:22）。

### 卖点 / 退出

- **止损位两套口径**（稿 36:27~36:49）：
  - **日线**：用前高作止损线，如 14.01；
  - **五分 K**：用五分 K 的最低价，如 13.95。
  - 规则：**跌破就先出来／直接清仓；不破就横着等一根阳线**（稿 36:49、24:45）。
- **平台止损法**（稿 24:35~24:45）：设一个止损点位（如 15.85），不跌破就一直拿着博弈一根阳线，一旦跌破直接清仓。
- **错过第一买点就不做**：今天才选出来已经晚了（稿 10:20、21:00、22:29）。
- **遇到矛盾点优先放弃**："一旦回踩也弱了，算了，眼不见心不烦"（稿 35:34、38:36）。
- **放量杀＝前一日是浮筹板**〔?〕：昨天拉虚高、今天以便宜价跑，量放出来就该走（稿 19:07、19:38）。
- **缩量过前大量后再缩量加速** → 容易爆量见顶 → 要防回调（稿 21:28）。
- 本篇**无仓位分配、无止盈比例、无持有天数**规则。

## 案例分析

> 以下案例均为视频录制时点（2025-07-30 前后）的盘面个案，**实例为视频录制时点的个案，可复用的是方法而非结论**。本篇是实盘过票，UP 主自己也不主张把结论直接迁移。

### 一、留下观察型：航天动力——有主力但没有当下买点（稿 03:09~03:52）

形态：左侧前高反包过去 → 一根阳线 → **缩量调整**（＝有主力操盘）→ 叠加军工有预期 → 后续有走趋势可能。

结论：**先放着看**。近期／明天可能没有买点；最好后面洗盘到 **14.37** 不破，那才是低吸埋伏点位；如果它继续涨就不看了——没给舒服的入场点。

可复用的方法：**"有主力"≠"现在能买"**，必须等到洗盘至关键位才谈买点；不给就不做（"等一个有缘人"）。

### 二、吃货三段式：居然之家（稿 04:41~05:14）

形态：第一波**放量** → 次日**接着放量**（这两根基本可确认是吃货）→ **缩量调整** → 洗盘 → **突破左侧**。

关键位：下方支撑回踩不破可看；上方点位若高开回踩不破可能有上升空间〔?〕。

结论：**形态确实可以，但当前没有题材加持，先放着，最后再删。**

可复用的方法：**"放量 → 再放量 → 缩量调整 → 突破左侧"是本篇最标准的吃货形态链**；缺题材加持只进池不下单。

### 三、否决型：先下电子〔?〕——平台假突破（稿 03:54~04:26）

形态：这里是筹码密集成交区，里面一大堆资金在做 T。要转强必须站上 26.77，再来一次平台突破，相当于平台内资金达成一致。

否决理由：**这种平台突破容易骗炮**——你看到突破去做接力，次日甚至当天就直接爆大量砸下来，这叫假突破；而且这个平台调整得也不好看。

可复用的方法：**密集成交区上方的平台突破＝高假突破风险**，突破当天/次日爆大量即证伪。

### 四、否决型：多伦科技——尖角波被砸（稿 05:18~05:39）

形态：左侧平台压力大（已否决一次）；当天爆量。

否决理由：爆量要分被动还是主动——**净额流出＝散户接盘居多**；分时是尖角波，**看尖角波还要看盘口**，这里是被砸了＝主力兑现、被左侧资金砸。短期反包比较难。

可复用的方法：**爆量必须配净额方向看**；**尖角波必须配盘口看**。

### 五、否决型：大恒科技——缩量板没有买点（稿 05:41~06:19）

形态：当天走 AI〔?〕老大，直接缩量板。

否决理由：**缩量板是没有买点的**，便宜老大也一样——需要买点后置，等题材走强、充分换手后点火才安全。有老铁说"他回封了我打板了"，UP 主的回应是：说得很清楚要题材走强，**早盘题材都直接兑现了，这就没有买点**。

可复用的方法：**缩量板不接**；题材当日已兑现的票，即使回封也不做。

### 六、否决型：申通快递——孕线〔?〕与乌云盖顶（稿 11:39~12:04）

形态：一根红 K 完全把前面的黑 K 包住（UP 主称之为"孕线"〔?〕）；若阴线是从高点杀到低点，那叫**乌云盖顶线**。

否决理由："一片祥和之中，孕育着危险。"

可复用的方法：**红 K 完全包住黑 K 的形态是否决信号，不是承接信号。**

### 七、否决型：张江高科——左侧套牢盘过大（稿 14:14~15:07）

形态：已开始走趋势，科技板块在动；但后续需要放量去解放左侧资金，阶段可能是震荡走高或横盘整理。

否决理由：左侧套牢 **92 亿**、当时成交都是八九十亿，而当前才三四十亿——相当于要"每天众筹三四十亿成交去消化左侧套牢盘"，工程量太大、不确定性太高，不去了。

可复用的方法：**"只做锦上添花，不做雪中送炭"**；横盘整理可以低吸埋伏占便宜，直接往上走就不去。

### 八、龙头预案：西藏天路（稿 12:42~13:29）

数据：左侧资金 **93 亿**，当日成交 **72 亿** → 至少锁住 **20 多亿** → 当日极重要的风标，其反馈影响整个题材走势。

当日实际：水下开 → 开盘拉升稳住整体题材 → 带动的是**弱修复**（不是强修复）。强修复需要低开急拉直接拉红，或直接高开，当天都没有。

可复用的方法：**用"左侧资金 − 当日成交 ＝ 锁住的资金"量化一只票的分量**，再用它的开盘表现做龙头预案。

### 九、主力明牌：单数控〔?〕——烂板放量吃货 + 缩量整理（稿 30:09~30:48）

链条：一个烂板都是放量 → 放量先涨停 → **这里很明显是吃货** → 次日水下是**缩量整理** → 说明筹码很稳固 → 同时**净额很亮眼** → 次日一个高开就很容易上车。

UP 主评价："对认真复盘的老铁而言这就是明牌，基本主力明牌在做。"

可复用的方法：**"烂板放量（吃货）→ 次日缩量整理（锁筹）→ 净额亮眼 → 高开上车"** 是本篇最完整、最可复用的一条链。

### 十、尾盘埋伏：新森〔?〕（稿 31:43~33:08）

链条：放量突破（有资金在干活）→ 次日一根很小 K 线**缩量整理**（筹码锁住）→ 再一根阳线。

买点：盘中看净额可适当低吸；**尾盘净额这么多，直接尾盘埋伏**——因为形态上已经突破高点，尾盘净额流入这么多，肯定有资金在抢筹。

UP 主的复盘反思：昨天没看那么细，如果昨天复盘到尾盘净额这么亮眼，今天就可以关注。

两个买点：**埋伏买点**（缩量整理那天的尾盘）与**加速买点**（再一根阳线当天，看净额当天进、尾盘埋伏）。

### 十一、止损设定：光电〔?〕与金箔〔?〕（稿 24:35~24:49、36:14~36:54）

- **光电〔?〕**：平台不跌破就一直拿着博弈一根阳线，止损位设 **15.85**，一旦跌破直接清仓。
- **金箔〔?〕**：放量吃货 → 缩量调整（回踩五日线但缩量＝洗盘动作）；低吸点在前高 **14.01**，**14.01 可做止损线**；或用五分 K，点位 **13.95**，**跌破先出来，不破就横着等一根阳线**。

可复用的方法：**止损位优先用"前高"或"五分 K 最低价"这两个客观锚点**，不用百分比。

### 十二、矛盾点放弃：金箔〔?〕的另一面（稿 35:29~35:41）
