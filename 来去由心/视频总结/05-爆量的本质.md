## 核心观点

1. **爆量 = 充分的筹码交换**：想买的都买了、想走的都走了（稿 04:43）。因此爆量也是**一次主力成本重置**——左侧低位筹码可视为已清空，主力最新成本落在爆量那根K线的位置（稿 36:14）。
2. **爆量当天大多看不出谁占优**，方向要等次日高低开揭晓；只有极少数情况（需大局观+盘口功力）当天可判定（稿 05:05，09:03）。
3. **位置定概率，次日定结论**：底部爆量偏吃货、顶部爆量偏出货，但主观定性必须服从盘面信号（稿 09:56，17:02，22:15）。
4. **短线不看高低，只看强弱**：恐高的本质是算错了主力成本位置，离主力成本越近越安全（稿 36:14–37:37）。
5. **爆量必须放在当时市场量能环境里看**：同样30多亿，在1.6万亿的市场里是吃货量级，在四五千亿的市场里就是顶部爆量（稿 34:30）。

## 行情判断

### 爆量的判定标准（稿 12:23–13:55）

- **底部区域用成交量**：往前看八九个月到一年的量柱，比第二高高出 **30%以上** 即算爆量；不抠死，明显一骑绝尘也算。
- **高位改用成交额**：每天爆出三五十亿资金时，用金额口径判定（如 39.61亿、44.27亿、52.99亿）。
- **平量**（两柱差不多高）与**阶梯式相对增量**都不算爆量，没有买点（稿 15:37，15:55）。

### 爆量后的方向判断流程

```
爆量当天（多数判不出）→ 次日高开转强 = 吃货 = 买点
                      → 次日低开走弱 = 出货 = 卖点（竞价即最快出局点，稿 00:53）
```

### 当天可验证的"承接"证据

1. **下探不破昨日最低价** = 有资金维护；跌破且不能快速收复 = 转出货（稿 20:19）
2. **大量被缩量反包**（32亿被22亿反包）= 昨天资金没卖、筹码稳定（稿 23:13）
3. **高开后下杀跌破昨低但马上收回**、随后拉过开盘价 = 主力表态转强（稿 35:03）
4. **开盘急拉**本身是主力表态"想往高处做"；盘中急杀多为恐慌资金（稿 21:13）

### 顶部信号线

- **顶部爆量 + 日内分时大震荡**（如从+9.61到水下-2.88）= 见顶信号线（稿 16:26–17:35）
- 信号线后两种走法：次日低开 = 基本见顶；次日高开 = 可能做**复杂头部**（主力横住做解套板/骗炮板，反包中出完尾货再下来，稿 17:35）
- **逃命量**：左侧高点未反包前，中途爆出远超左侧的巨量（118.4亿 → 176亿）= 最后卖点（稿 30:48）
- **缩量加速阶段** = 持筹者盛宴，后面全是风险，不参与（稿 28:20）

## 操作逻辑（选股·买点·卖点）

### 选股

- 重点监控**出现爆量形态的票**——若是吃货后面还有一波（稿 19:49）
- 同等机会下只做"市场最靓的仔"，注意力是稀缺资源（稿 34:01）

### 买点清单

| # | 类型 | 触发条件 | 出处 |
|---|---|---|---|
| 1 | 底部爆量次日高开 | 相对底部 + 爆量 + 次日高开 | 稿 09:56 |
| 2 | 竞价凹槽B点（三一B点） | 爆量次日竞价抢筹甚至一字 | 稿 10:41 |
| 3 | 平开急拉 | 爆量次日平开略下探后急拉，下探不破昨低 | 稿 20:19 |
| 4 | 下杀收回确认 | 高开下杀破昨低但马上收复，拉过开盘价 | 稿 35:03 |
| 5 | 缩量反包大量 | 更小量能反包爆量K线 = 筹码稳定 | 稿 23:13 |
| 6 | 多方炮确认 | 山字形三K，次日高开于关键价（如6.97）之上 | 稿 23:46 |
| 7 | 中继再爆量再高开 | 每次新爆量重走一遍流程 | 稿 14:24 |
| 8 | 当天即判定的吃货（顶级） | 净额流出但盘口是吃货 + 大盘主升 + 题材对 + 位置不高 | 稿 40:03 |

### 卖点清单

| # | 类型 | 触发条件 | 出处 |
|---|---|---|---|
| 1 | 爆量次日低开 | 尤其顶部爆量后，竞价就是最快出局点 | 稿 00:53 |
| 2 | 顶部信号线 | 顶部爆量+分时大震荡，次日给机会必逃命 | 稿 30:12 |
| 3 | 破昨低不收复 | 拉升后跌破前低且不能快速收复 | 稿 20:19 |
| 4 | 复杂头部/解套板 | 顶部信号线后的反包先怀疑是骗炮板 | 稿 17:35 |
| 5 | 逃命量 | 未反包左侧高点前中途爆巨量 = 最后卖点 | 稿 30:48 |
| 6 | 跌停出货 | 跌停当天就得跑，次日有机会接着出尾货 | 稿 38:48 |

### 仓位管理（稿 26:07，38:16）

- 第一买点约三成仓 → 第二买点约两成仓 → 第三买点约一成仓；第四买点之后"可去可不去、持股看戏"
- 市场环境不好再打折（两成→一成）

## 关键规则与数字

- 爆量判据：量柱高出第二高 **30%以上**；高位用**成交额**（稿 12:23）
- 市场量能参照：当时四五千亿/天 vs 现在1.6万亿/天，决定"30多亿"是出货还是吃货量级（稿 34:30）
- 大众交通关键数字：底部股价两三块 → 7.41；顶部爆 **52.99亿**，分时 +9.61 → -2.88（稿 09:56，16:26）
- 海能达关键数字：22亿缩量反包32亿；多方炮确认价 **6.97**；高位爆量 **44.27亿**；逃命量 **176亿**（左侧118.4亿）（稿 23:13–30:48）
- 深圳华强：13板爆30多亿；第二B点爆量 **39.61亿**（稿 34:30，35:49）
- 仓位：三/两/一成递减（稿 26:07）

## 案例分析

- **大众交通**：底部爆量（吃货）→ 三次"爆量+次日高开"给出三个B点 → 平量/增量区无买点 → 顶部爆52.99亿+分时大震荡=见顶信号线 → 主力做解套板复杂头部出完尾货 → 空头波段（稿 09:35–18:50）。
- **海能达**：中东BP机事件驱动，机构对标九安医疗炒作走成市场合力（稿 32:16）。五次"爆量→次日高开/急拉"买点，辅以"缩量反包=筹码稳定""多方炮"确认；高位缩量加速不参与；最终天地板式顶部信号线+176亿逃命量终结（稿 19:31–31:39）。
- **深圳华强**：底部爆量第一B点（当时非最靓的仔被错过）；13板爆30多亿看似顶部出货，但次日高开+下杀收复昨低=吃货表态，演示"成本重置"核心逻辑；39.61亿爆量再给一个B点；最终跌停=明确出货（稿 33:52–38:48）。
- **中粮资本**：9月26日、924行情主升起涨点、大金融、位置不高——净额流出但盘口+环境综合判定当天吃货，属"极少数当天可判定"的实例，爆量当天即第一B点（稿 39:45–41:00）。
- **九安医疗**：逃命量的旁证——左侧没走掉的资金在中途爆量处逃命出局（稿 33:20）。
