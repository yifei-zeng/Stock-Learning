## 一句话结论

上证15年统计：节前弱（40%）、节后强（66.7%）、跳空是主要变量；持币还是持股，答案只在你自己的四问里。

## 一、15年统计（2011—2025，上证指数）[02:02]

数据口径：2011—2025 年上证指数历史数据的描述性统计，UP主称来源为万得（Wind）及市场公开统计 [00:11]。对照窗口三个：节前 5 日、节后首日、节后 5 日。**全部数字只作概率坐标，不作预测** [01:07]。

|---|---|

| 节后首日上涨概率 | 66.7%（15 年十涨五跌） |
| 节后 5 日上涨概率 | 66.7%（约 2/3） |
| 节前 5 日平均涨幅 | +0.89% |

三效应一句话记全 [00:45]：**节前偏弱、节后偏强、跳空是主要变量**。

两个统计陷阱：
1. **单一极端年份会显著改变均值**——2024 年那波把平均数拉高一大截，这是平均数的最大痛点 [04:06]；
2. **胜率是概率、幅度才是伤害**——66.7% 听着很好，但那 33.3% 落在你身上才算数 [05:31]。

## 二、效应机制：节前为什么弱、节后为什么强 [03:15]

节前偏弱三个来源 [03:21]：

| 来源 | 机制 |
|---|---|
| 资金离场 | 假期要用钱、要还钱，部分资金提现兑现 |
| 观望情绪 | 假期外部环境不确定，增量资金不愿进场 |
| 避险 | 休市期间无法交易，持仓意愿下降 |

表现：节前通常缩量、偏弱势震荡——**这是统计倾向，不是规律** [03:47]。

节后偏强三个来源 [04:42]：

| 来源 | 机制 |
|---|---|
| 资金回流 | 节前离场的资金回来 |
| 情绪修复 | 假期观望情绪有效释放 |
| 补涨效应 | 外围走强则节后存在补涨动力 |

**先手打后手** [05:42]：节前最后一个交易日尾盘常出现资金回流；先手卡的是节后牌——你还在观望，人家前一天已经买完。

反例（统计不是保证）[05:12]：
- 2018 年：市场整体极差，节后回来反而下跌；
- 2024 年 10 月 8 日：高开 10%、收盘收涨 4.5%，节后 5 日连续下跌——节后偏强照样套人；
- 口述另提 2019（或 2020，口述不清）、2011、2014、2015 年节后首日下跌，未逐一验证（见读后提醒）。

## 三、决策四问：数据之后，答案在你自己身上 [06:26]

四问没有标准答案，别人的答案对你没有用 [07:18]。

| 四问 | 判据 | 决策规则 |
|---|---|---|
| ① 钱多久要用 | 3 个月内要用：随时可能被抽走 | 任何波动/回撤都是真实损失，亏不起 → 原则上不持股过节 [06:40] |
|  | 1 年以内不用 | 可承受阶段性波动，但不宜满仓 [08:45] |
|  | 3 年以上不用 | 风险敞口可放大，不用在乎短期波动 [08:49] |
| ② 持仓在什么位置 | 低位长期 | 承受度高，跌下来不影响长期逻辑 → 可安心持股过节 [10:03] |
|  | 中位主线 | 主线在逻辑就在，承受度尚可 → 可留一部分 [10:09] |
|  | 高位刚追／非主线 | 承受度低；无消息面依托，高位回撤直接打到心理价位 [10:17] |
| ③ 跌多少睡不着 | 假期跌 5% 睡得着吗？睡得着和睡不着是两个决策 [06:54] | 承受度不是数字问题，是睡得着觉的问题；睡不着＝仓位太重→降仓；会情绪化操作就不做 [10:53] |
| ④ 假期有多长 | 无法交易的时间越久，累积的不确定性越高 [12:10] | 休 1 天：可控性较高；7 个自然日：中等；春节：可控性最低 [12:14] |

一句话自测 [10:35]：假设假期没有任何利好、节后低开，你手上的还拿得住吗？想拿＝持股，不想＝持币。

久期铁律 [08:56]：保险资金能躺 20 年，你的钱可能今年明年要交房租——久期不相等，可承受强度就不一样；不要轻易模仿别人的答案。

## 四、按资金属性的三种选择 [13:09]

| 资金属性 | 规则 |
|---|---|
| 短线、带杠杆 | 杠杆成本照付，且无法对冲跳空低开 → 按清单第 4 条优先降杠杆/降仓位 [13:11] |
| 波段、做主线结构性行情 | 逻辑在就留一部分，但不要全部暴露在跳空风险中 [13:19] |
| 长期、拿指数 | 择时成本远高于择时收益；统计上节后偏强，越动越吃亏 [13:26] |

以上是按资金属性的分类描述，不是操作建议；你属于哪一类，由决策四问决定 [13:36]。

## 五、四个误区与硬规则 [13:50]

| 误区 | 硬规则 |
|---|---|
| 1. 把统计当预测 | 统计只用来校准风险预期，不能告诉你今年落在哪；先问自己「最差亏 7.6%，扛不扛得住」[15:06] |
| 2. 满仓赌方向 | 赌赢是运气，赌输没人替你扛 [13:57] |
| 3. 节前最后一天才做决定 | 那天所有观点集中输出、情绪极端、时间仓促，很难独立思考。规则：**节前 2~3 个交易日把决定做完并写下来**；写下来的决定不容易被情绪推翻。最后一天只做一件事：若要接回仓位，只看资金回流信号，不追冲高 [15:20] |
| 4. 抄别人的答案 | 资金属性不同，答案不同。他说持股过节就问他「你拿了多少」；说持币过节就看他手上有没有票 [14:49] |

> 「没有人会为你负责，不管这个人多牛逼。」[17:23]

## 六、落地八条决策清单（节前 2~3 个交易日完成并写下）[16:00]

前四条认清自己：
1. 钱多久要用（3 个月内要用 → 原则上不持股）；
2. 最快能承受多少回撤；
3. 持仓在哪个位置（低位/中位/高位，是否主线）；
4. 有没有杠杆（有 → 优先降低）。

后四条想清两种情况：
5. 目标仓位是多少（按系列第六期的仓位规则计算）；
6. 跳空高开怎么办；
7. 跳空低开怎么办；
8. 什么时候做决定、若最后一天介入应如何介入。
