## 一句话结论

财报只用来排雷、不用于预测涨跌：10 分钟速读的固定顺序是「审计意见（标准无保留才继续）→ 三张表交叉验证 → 八个指标拉 3 年趋势 → 扫异常科目」，任何一票否决项命中就放弃。核心判据只有一句：**净利润是观点，现金流是事实**，两者长期背离，利润大概率只是账面数字。

## 一、三个误区与看财报的时间窗口

| 误区 | 正解 |
|---|---|
| 财报能预测涨跌 | 好财报不代表明天涨，坏财报不代表明天跌。**财报是排雷，不是择时工具** |
| 净利润高就是好公司 | 净利润是观点，现金流是事实；现金流越大，越有能力开展新业务、自我推动 |
| 看一期财报就够了 | **至少看 3 年**看趋势，再对照同行看位置；要环比、同比，对比过去几年和现在的盈利 |

看财报的时间窗口：**1、4、7、10 四个月**重点盯财报内容（对应定期报告披露节奏，逐字稿原文为"147十"）。

## 二、三张表各自回答什么

| 报表 | 回答的问题 | 可信度 |
|---|---|---|
| 利润表 | 一段时间内赚了多少：收入、成本、利润各是多少 | 中等可信度，含估计 |
| 资产负债表 | 某一时间节点的家底：资产多少、负债多少 | 含估计 |
| 现金流量表 | 钱真的进口袋了吗：经营、投资、筹资各如何 | **最难修饰、最不容易骗你的一张表** |

**利润表要点**：

- 结构链条（逐字稿表述有残缺，见读后提醒）：营业收入 − 营业成本 = 毛利 → 减三费 → 减（加）非经常性损益 → 净利润；**每一层都在漏**。
- 营收增速要追问来源：是**涨价催化**还是**自身放量**。（AI 方向举例识别不清，见读后提醒。）突然跳升或跳降都要追问原因：是产品赚钱，还是主营业务新拓展了新业务。
- **三费**：销售/管理/财务费用占比是否异常。销售费用一般占营收 **14%~20%**（金融类公司销售人员占比高、销售费用为主）。
- **非经常性损益**（卖资产、政府补助、退税等）撑起来的利润**不算数**，但确实能刺激一下当时股价。
- **扣非净利润才是靠主业真正赚到的钱**。

**资产负债表要点**：

- 恒等式：**资产 = 负债 + 所有者权益**；左边是钱去哪儿了，右边是钱从哪儿来。
- 资产端四科目：**货币资金**（账上现金，维持运营必需）；**应收账款**（卖出去但没收回来的钱——要看欠款方是谁，欠款方不行就等于收不回）；**存货**（双刃剑：主营产品涨价周期里存货越多越值钱，跌价周期里存货越多压力越大、每天都在贬值）；**商誉**（收购溢价，**最容易暴雷的一项**）。
- 负债端：**有息负债**（短期借款 + 长期借款）是真正要还的钱；**应付账款**是占用上游的钱、议价能力的体现，**越多越强**（好公司一定欠上游钱、而下游不一定欠它钱）。应付账期参考：小米约 **65 天**，普通大型商超一般 **60~90 天**。

**现金流量表要点**：

| 活动 | 内容 | 判据 |
|---|---|---|
| 经营活动 | 主业带来的现金进出，**核心** | 长期为正才具备自我造血能力 |
| 投资活动 | 买设备、买公司、买理财 | 扩张期为负很正常，但要真看到回报；要区分"真做新增业务"还是"为市值管理" |
| 筹资活动 | 借钱、还钱、分红、融资 | **长期靠筹资输血要警惕**，可能 ST、还不起钱 |
| 股权质押 | — | 还得起钱 → 股价上去自然赎回/减持；**长期无法造血 + 股权疯狂质押 = 雷** |

## 三、三表交叉验证（单看一张必然被骗）

| 交叉点 | 异常判据 |
|---|---|
| 应收账款 vs 营收 | 应收增速远高于营收（举例：应收涨 80%）= 货卖出去钱收不回来。正常账期国内公司约 **60~90 天**；客户压货周期变长、所有大客户都在压款 = 议价能力不够（护城河深的公司多为**先款后货**） |
| 经营现金流 vs 净利润 | 利润涨、现金流不涨 → 利润质量存疑（"赚 3000 万，卡里只有 200 万，剩下 2800 万去哪了？"） |
| 有息负债 vs 账上现金 | 账上有钱还大量借钱 = **大存大贷**；存款利息明显低于贷款利息，必须解释清楚在干什么 |
| 存货 vs 营收 | 存货比营收涨得还快 = 卖不动、大量囤货、跌价风险 |

> 原话（校正后）：「单看一张表，看不出问题。三张表必须交叉验证，单看一张必然被骗。」

## 四、八个关键指标速查表（全部拉 3 年看趋势，不看单点）

四个看盈利质量：

| 指标 | 算法 | 判据/阈值 |
|---|---|---|
| 毛利率 | (营收 − 营业成本) ÷ 营收 | 看**趋势** + 同行对比；绝对数字没有意义 |
| 净利率 | 净利润 ÷ 营收 | 看**稳定性**；忽高忽低 = 主营业务盈利能力不持续 |
| ROE（净资产收益率） | 净利润 ÷ 净资产 | **长期 > 15% 较优**；5~10 年维持较高水平才算有护城河 |
| 净现比 | 经营现金流 ÷ 净利润 | **持续 < 1 就有问题**（只有利润没有现金，钱去哪了必须讲清楚） |

四个看风险：

| 指标 | 算法 | 判据/阈值 |
|---|---|---|
| 资产负债率 | 总负债 ÷ 总资产 | 看行业基准：**制造业 30%~40% 正常，60% 以上一定有问题**；银行、地产天然高（存款就是银行的负债） |
| 流动比率 | 流动资产 ÷ 流动负债 | **长期 < 1 = 短期偿债有压力**（短债 5 亿、手上只有 2 亿 → 只能继续借） |
| 应收账款周转天数 | — | **30 天以下说明经营非常好；120 天以上"有鬼"**；账上必须备**半年现金流**才能扛住偶发事件 |
| 商誉 ÷ 净资产 | — | 占比高 → **计提减值风险**；最典型是 IP 经济、明星工作室、靠单个老板个人 IP 讲故事的公司 |

## 五、三类排雷信号（信号 ≠ 定罪，但必须解释清楚）

| 类别 | 信号 | 本质 |
|---|---|---|
| 收入质量 | 应收增速远高于营收、回款周期变长、渠道/大客户大批量压货 | **议价能力不够**：护城河越深回款越快（先款后货）；被压款而没话说 = 低端供应商 |
| 现金流与偿债 | 净现比长期偏低、短期负债率过高 | 还得起钱吗 |
| 资产端 | 周转天数拉长、商誉占净资产偏高、**资金去向不明**（其他应收款异常、过桥） | 资金去向解释不清 = **信息披露违规，可能被直接 ST**；"这个雷很大，你顶不住" |

## 六、10 分钟速读四步 + 一票否决清单

| 步骤 | 动作 |
|---|---|
| 1 | **先看审计意见**：**标准无保留意见才能继续**；保留意见、审计拒绝签字 → 后面全都不用看 |
| 2 | **三表交叉**：应收 vs 营收、存货 vs 营收、净现比（经营现金流 ÷ 净利润）、货币资金 ÷ 有息负债 |
| 3 | **八个指标拉 3 年趋势**（第四节表格），不要只看一年 |
| 4 | **扫异常科目**：商誉、其他应收款、非经常性损益、存货 |

一票否决清单（任一命中即放弃该公司）：

| 否决项 | 处理 |
|---|---|
| 审计意见非"标准无保留" | 直接不看，后面都与你无关 |
| 商誉占净资产比例高 | 卡掉 |
| 存货周期突然拉长 | 卡掉 |
| 营收和增速对不上 | 卡掉 |
| 审计给了无保留、但三类排雷信号明显存在 | **这家审计机构有问题 → 该机构审计的所有上市公司全部拉一遍**（审计相关问题会拖累其全部客户） |

财报的能力边界：

- **能**：避开雷。
- **不能**：预测短期涨跌；只看一期（至少看 3 年；连续两年亏损会崩）；只看绝对值（要看负债率等相对指标）。

> 原话（校正后）：「财报能够避开雷，但是不能告诉你在哪儿能捡钱。」
