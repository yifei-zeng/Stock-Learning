# 中短线 · 选股 + 买入 + 卖出 + 仓位 完整策略

> 依据：《认知税系列》第 2、3、4、5、6、7、8、9、11、12 篇（总结见 `视频总结/`）
> 定位：**中短线**——持有周期约 **3~15 个交易日**（数天到数周），介于超短线(1~3天)与波段(数周~数月)之间。
> 免责：本策略是方法论提炼，不构成投资建议、不推荐任何具体标的、不承诺收益（UP主多篇声明仅作个人梳理）。
> 标注规则：【篇目】= 来源；「经验值」= UP主口述阈值，需按自身校准；「不确定」= 逐字稿识别不清。

---

## 0. 先明确一件事：中短线 = 短线战术 + 波段纪律

中短线不是"拿久一点"的短线，而是把**第2篇的短线择时战术**和**第3篇的波段纪律**结合起来：

| 维度 | 中短线应该这样定 |
|---|---|
| 盯盘 | 需要**每日复盘**，但不需要全程 9:15–15:00 盯盘（这是超短线的要求，做不到就排除纯打板/接力）【03】【02】 |
| 核心打法 | **启动突破 + 高低切** 为主（时间要求低、适配中短线）；**接力/弹性套利**为进阶（需盯盘+懂股性，可选）【02】 |
| 情绪 | 短线靠情绪周期赚钱，但**纪律用波段的**（分批止盈、写死止损）【04】【09】 |
| 盈亏结构 | 小亏小赚 + 大赚一次就够；**破位即走、启动不来、涨多了不追**【03】 |

> 定位自检（3分钟，来自第2篇6问）：①能不能每天全程盯盘？②这笔钱5年内会不会动？③上一笔亏损是到止损位走的还是"再等等"？④有没有不可谈判的交易规则？⑤连亏3次第一反应是复盘还是加仓？⑥能不能说出持仓公司的护城河？
> ①答"不能"→ 排除纯接力/打板，但**不影响做中短线**；③⑤答"再等等/加仓"→ 先补纪律再动手。

## 1. 选股（四步漏斗，从方向到个股）

### 第1步：选方向 —— 只在主线「发酵期」动手【09】

任何主线都走「启动→发酵→高潮→退潮」四段。中短线**只做②发酵期**（逻辑已清晰 + 情绪未极端）。

**主线确认三信号（缺一条只算"今天涨得不错"）：**
1. 有**龙头**：大市值票走出强度，或高度票突破压制（如五板压制下打到六、七板）
2. 有**梯队**：龙头之外形成 5-4-3-2-1 的完整梯队
3. 有**持续性**：连续 2~3 天保持活跃（不要求天天第一）

**题材分级（决定持有节奏）：**
| 级别 | 驱动 | 做多久 |
|---|---|---|
| 政策级 / 产业级 | 国家政策 / 产业趋势 | **中短线可做波段**（数天~数周） |
| 事件级 | 单一事件/短期消息 | 快进快出（1~3天），不留恋 |

> 错配警告：**别拿"三个月"的方式去持有一个"三天"的消息**【09】。

**每日方向跟踪（收盘后写4行，不写个股只写方向）：** 龙头走到哪 / 跟风票变多还是变少（变多=进②，变少=直接进④）/ 讨论的人变多还是变少 / 量能能否持续放大。当"有点东西的和没东西的财经UP主都在聊这个方向"时 = 风险信号【09】。

### 第2步：在主线内选股 —— 三种战术【02】

| 战术 | 适用场景 | 中短线如何用 |
|---|---|---|
| **启动突破（主力）** | 主升浪，日线+周线**双突破** | 主升方向里找放量突破平台/前高的票 |
| **高低切（主力）** | 行情还在，板块内/板块间出现**补涨、后排异动** | 龙头买不进或太高时，切到同板块补涨股 |
| **超跌反弹（辅助）** | 高位板块结束后的**被动套利** | 只用轻仓（≤5成），目标只赚 2~4 个点，次日冲高就走 |
| 接力（进阶·需盯盘） | 情绪流主导，看**封单比** | 情绪好+封单比高才做；不做时宁可空仓（龙空龙） |
| 弹性套利（进阶·需懂股性） | 20cm/30cm 高弹性品种 | 赚钱效应在哪就去哪；板块拉升拉哪几只票要心里有数 |

**共同前提（硬门槛）：股性必须活跃。** "无股性无情绪、无资金、无板块催化——不要聊"【02】。

> 打法错配是亏钱主因（第2篇反复强调）：**别用超跌反弹的轻仓去做启动突破；别用接力的短平快心态去做高低切（高低切可以等一等）**【02】。

### 第3步：财报排雷（快速版，先排雷再看方向）【08】【11】

买入前对个股过一遍，**任一命中即放弃**：

| # | 排雷项 | 量化条件 |
|---|---|---|
| 1 | 审计意见 | 非"标准无保留意见" → 放弃 |
| 2 | 净现比 | 经营现金流÷净利润 持续<1 → 放弃 |
| 3 | 应收 vs 营收 | 应收增速远高于营收（周转>120天有鬼）→ 放弃 |
| 4 | 存货 vs 营收 | 存货涨得比营收快 → 放弃 |
| 5 | 大存大贷 | 账上大量现金仍大量借款 → 放弃 |
| 6 | 商誉 | 商誉÷净资产占比高 → 放弃 |
| 7 | 流动比率 | 长期<1 → 放弃 |

> 财报只排雷、不择时；好财报不代表明天涨【08】。中短线不必像长线那样深挖护城河，但**雷必须排**——一次暴雷能吞掉十次短线利润。

### 第4步：量价确认【02】【12】

| 信号 | 含义 | 动作 |
|---|---|---|
| 价涨**量增** | 健康，资金真实进场 | ✅ 可买 |
| 价涨**量缩** | 动能衰竭 | ❌ 不买（或持有中减仓） |
| 放量**滞涨** | 顶部信号，有人出货 | ❌ 不买 / 卖出 |

## 2. 买入（可执行的条件 + 下单前检查）

### 2.1 择时触发（A组，任一满足即可进入观察）
| 编号 | 触发条件 | 量化定义 |
|---|---|---|
| A1 | 启动突破 | 收盘**放量**突破前高/平台，且**日线+周线**都突破【02】 |
| A2 | 高低切 | 龙头封板/高位，同板块**补涨股**放量异动（后排启动）【02】 |
| A3 | 回踩不破 | 回踩 MA20（生命线）不破后放量收回【11，参数「不确定」】 |
| A4 | 双底企稳 | 日线双底，第二只脚不创新低【02】 |

### 2.2 确认条件（B组，全部满足才下单）
- B1 该方向在**②发酵期**（三信号齐备）
- B2 个股在**年线上方**、MA5>MA20>MA60 多头排列
- B3 价涨**量增**（非量缩、非滞涨）
- B4 通过**财报排雷**（第1步第3层）
- B5 已算好**止损位**和**下单量**（先风控后进场）

### 2.3 下单前 6 问（逐条打勾，不是"感觉可以"）【04】【11】
1. 它在我的主线方向和标的池里吗？
2. 排雷过了吗？
3. 触发条件 A + 确认条件 B 都满足吗？
4. 止损位在哪？跌破我走不走得了？
5. 这一笔最多亏我总资金多少？扛得住吗？
6. 我是**按计划动手**，还是看到别人赚钱手痒？

### 2.4 下单前写反向观点（写不出 = 没想清楚 = 不做）【05】
我可能错在哪 / 什么信号证明我错了 / 最坏亏多少。

## 3. 卖出（止损 + 止盈，全部写死）

### 3.1 止损（触发任一即离场，不商量）【04】
| 止损 | 条件 | 优先级 |
|---|---|---|
| **资金止损** | 单笔亏损达总资金 2% | ⭐最高 |
| 前低止损 | 跌破近期前低/技术低点（个股**不做左侧抄底**） | 高 |
| 均线止损 | 跌破 MA20（生命线） | 高 |
| 固定百分比 | 亏 8%~10% 走（嫌高用 5%~6%）「经验值」 | 兜底 |
| 逻辑止损 | 买入逻辑破坏（主线退潮/财报暴雷）→ 不管盈亏都走 | 高 |
| 情绪止损 | 状态不对（极致焦虑）→ 清掉不碰 | 兜底 |

**硬纪律**：一天最多止损 N 次（N 自己定，默认 3 次），超过当日停手【11】。

### 3.2 止盈（中短线首选"分批止盈"，别贪）【04】【02】
| 方式 | 规则 |
|---|---|
| **分批止盈（首选）** | 仓位分 3 份：浮盈 **+10% / +20% / +30%** 各卖一份；先把本钱拿回来，让子弹飞「经验值」 |
| 目标止盈 | 到 **+20%** 就收手（新人可只设这一条） |
| 动态跟踪 | 涨了把止损线抬到成本线，再涨再抬（例：10→10.2 设 10.1→10.5 设 10.3） |
| **情绪止盈** | 情绪过热/人声鼎沸（所有人都聊）→ 分批减仓；情绪读数>80 预示过热【02】 |
| 短线专用 | 打板票**炸板**减一部分 → 回落到 **8 个点**减一部分 → 跌破均线再减一部分【04】 |

**减仓量价信号**：价涨量缩=动能衰竭；放量滞涨=顶部【02】。

### 3.3 中短线持仓铁律
- 超跌反弹：**赚 2~4 个点就够**，次日冲高立马跑【02】
- 事件级题材：**快进快出，不留恋**（三天的消息不用三个月的方式持有）【09】
- 短线**不聊格局**：位置破了就认亏，"格局"是失败时的遮羞布【02】

## 4. 仓位管理（完整）【06】

> 核心：**仓位管理不负责让你赚更多，只负责让你活到期望值兑现的那一天。**
> 期望值 = 胜率×平均盈利 − 败率×平均亏损；**高胜率≠赚钱**。

### 4.1 两条不可谈判的铁律【04】
1. **单笔最大亏损 ≤ 总资金 2%**
2. **月度累计亏损 ≤ 6%**（到线当月停手）

### 4.2 下单量公式（固定分数法，先有止损位才谈买多少）【06】
```
可买股数 = (总资金 × 2%) ÷ (入场价 − 止损价)
占用资金 = 可买股数 × 入场价
```
> 止损位越近买越多、越远买越少；同一笔 2% 风险，先定止损线再算股数。

### 4.3 仓位硬约束（写死）【06】【04】
| 约束 | 数值 |
|---|---|
| 单票最大仓位 | ≤ **10%** |
| 最大同时持仓 | ≤ **4 只**（3 只足够） |
| 最低现金比例 | 永远留 **10%~20%**（现金=你的选择权） |
| 超跌反弹/辅助仓 | ≤ **5 成**，机动仓更轻 |

### 4.4 三层仓位结构【06】
| 层 | 作用 | 中短线建议 |
|---|---|---|
| 底仓 | 跟上市场（宽基/基金） | 30%~40% |
| 机动仓 | 主线波段、启动突破/高低切 | 30%~40% |
| 现金 | 永远保留 | **10%~20%** |

### 4.5 加仓 / 减仓规则【06】
- **加仓唯一通行证 = 浮盈**；金字塔加仓（首笔1→2→3，每次递减，次数≤2）；禁止倒金字塔补仓（越跌越买越重）。
- **减仓四条触发**：①到止损位（不问理由不改线）；②买入逻辑破坏（不管盈亏都走）；③到目标位分批止盈，**第一批先减一半**；④单票仓位超限，超出部分无条件减。
- 半凯利：若用凯利公式算仓位，**砍半**使用（你并不确知真实胜率盈亏比）。

### 4.6 熔断 / 停手线【04】【06】
| 触发 | 动作 |
|---|---|
| 连续止损 **3 次**（哪怕两天内） | 立即停手，复盘，不交易 |
| 账户回撤 **10%** | 停手 3 天 |
| 月度累计亏损 **6%** | 当月停手 |
| 连续三个月亏损 **>15%** | 判定当前市场不适合你，暂停 |

## 5. 每日执行清单（照做即可）

**开盘前 30 秒**：今天触发条件是什么 / 仓位上限是多少 / 什么情况我不做。
**盘中**：只在计划内的触发点上动手；止损位触及即挂条件单，不靠意志力【04】。
**收盘后 15 分钟内**：五段式复盘（指数→情绪→资金→计划→推演）+ 主线方向跟踪表 + 这笔属于哪种错误（可避免/不可避免/系统性）。
**每周**：四步周复盘（验证预判/主线实况/改哪条规则/下周观察）。
**每月**：至少改出**一条规则**（没有产出规则=只在记账）。

> 自动化不是替你决定，而是替你避免情绪化执行：止损止盈挂**条件单**，预警设"跌破某线/换手率超多少/涨幅超多少"【04】。

## 7. 中短线最常犯的错（对照自查）【02】【09】【03】

1. **打法错配**：用超跌反弹的轻仓做启动突破、用接力心态做高低切。
2. **第四阶段进场**：以为在抄底，其实在接退潮的盘。
3. **级别错配**：拿三个月的方式持有一个三天的消息。
4. **破位不走、涨多了才追**：启动不来不干，等涨多了"这地方真好我要追"挂山顶。
5. **加杠杆/满仓**：杠杆让你丧失等待行情的资格【01】。
