## 新视频归档规则

1. 新投稿先看它属于哪个 B站合集（对照 `合集视频清单.md` 的映射表；查不到的进 `99-散稿/`）
2. 序号 = 该合集 `00-索引.md` 表中的「合集序」；散稿从 01 重新编号
3. 提取落位：`<合集文件夹>/逐字稿/2-完整逐字稿/`（散稿直接放 `99-散稿/`），后续按根 README 第五节 SOP 走 ①→⑤
4. 每个合集拉第一篇时，同时建齐 `视频总结/` 与 `逐字稿/{1,2,3}-…/` 子夹（结构照抄 `01-认知税/`）
5. 回写两处：该合集 `00-索引.md` 的本地状态列 + `合集视频清单.md` 的映射表
