# 08 · 题材炒作规律

> 来源：B站「来去由心」《顶级干货：股市小白题材炒作规律！买在分歧，卖在一致！》
> 链接：https://www.bilibili.com/video/BV1rMt864EwF｜时长：24分04秒
> 逐字稿：[`../2-整理稿/08-题材炒作规律.整理稿.md`](../2-整理稿/08-题材炒作规律.整理稿.md)（原始稿同名 .逐字稿.txt）
> 说明：UP 主的盘面实例均为视频录制时点（2024-2025年，DeepSeek 行情与 924 行情）的个案推演，**可复用的是方法而非结论**；个股仅作方法示例，不构成推荐。

## 核心观点

1. **一轮题材的运行是固定的六段：启动（冷/热）→ 高潮 → 分化 → 分歧 → 退潮 → 二波**；判断清楚"现在是第几段"，就知道该买什么、该躲什么（稿 22:00、22:09）
2. **题眼："买在分歧，卖在一致"**——一致最值钱的证据是"你买不到"（竞价一排一字）；分歧最值钱的证据是"强的票被错杀"（前排炸板、龙头爆量、冰点超跌）（稿 00:47、02:34、19:05）
3. **同一个信号在不同阶段含义相反**：竞价金额大，上升期是抢筹（真强），龙头开板当天是分歧大（假强，容易被砸死）（稿 11:38）
4. **短线炒作排序：逻辑第一，情绪第二，成本第三，技术第四**——硬逻辑可以卡掉纯情绪票（稿 09:33）
5. **真正区分小散和高手的是大局观**，即"现在是第几段"的判断力（稿 23:52）

一句话口诀：**高潮不接后排，分化必有回流，分歧买龙/做补涨，退潮管住手；买在分歧（冰点、前排炸板、龙头断板），卖在一致（竞价一排一字、强无可强）。**

## 行情判断（六段周期）

```
启动（冷启动/热启动）→ 高潮（强无可强）→ 分化（龙头不断板）
→ 分歧（龙头断板/爆量）┬ 次日反包 → 直接上龙头
                      ├ 温和断板 → 做低位补涨
                      └ 次日核按 → 退潮
→ 退潮（撤退龙诱多、空间板压制，利润垫跑、不开新仓）
→ 二波（反核/翘板、回光返照龙、冰点买龙，最后一口肉）
```

| 阶段 | 判定信号 | 核心动作 | 出处 |
|---|---|---|---|
| 冷启动 | 零星涨停 | 首板半路前排、一进二卡位晋级/低吸、二板以上卡位晋级+竞价三一+弱转强爆量转一致 | 稿 00:09 |
| 热启动 | 竞价 6~10 个一字 | 前排炸板低吸 / 竞价三一 / 中军 / 弹性标 / ETF | 稿 00:44 |
| 高潮 | 强无可强 | 竞价三一里选最强；"能买的不敢买"时敢买 | 稿 08:34、19:10 |
| 分化 | 龙头不断板、涨停家数递减 | 卡位晋级、汰弱留强、分化必有回流低吸核心票 | 稿 10:02 |
| 分歧 | 龙头断板或爆量 | 当天除龙头外都不看；次日三分支 | 稿 11:29、14:09 |
| 退潮 | 大单一字核按、撤退龙打高度 | 不开新仓，弱砍强留 | 稿 17:11、17:35 |
| 二波 | 冰点（大面积超跌 20%~40%） | 反核只做第一，套利就走 | 稿 19:05、19:40 |

**分化 vs 分歧的一句话区别**：分化 = 龙头不断板、继续打高度；分歧 = 龙头断板了（稿 11:29）。**断板跟爆量差不多一个意思**，本质是"接受市场检验"（稿 14:37）。

## 操作逻辑（选股·买点·卖点）

### 选股
- **前排判定看封单排序**：按竞价封单金额排序，封单最大的前 2~3 名基本不会开板，"第 4 名"就是能买到的最前排（稿 02:47）
- **先炸板的是后排，后炸板的是前排**——炸板顺序就是强弱排序；最先炸（早盘炸）的不接，等弱的全炸完"认输表态"后，被带开的前排才是低接机会（稿 02:10、02:31）
- **竞价三一三条件**：竞价换手/金额两市前三 + 有地位有身位 + 有硬核产业逻辑（稿 04:48）
- **换手票优于一字票**：主升期一字票没换手，到分歧时一字上去的见顶就没，换手上去的还能多走两个板（稿 09:04）
- **卡位晋级看逻辑硬度**：杭钢用"杭州本地算力+DeepSeek 关联"的更硬逻辑卡掉梦网（稿 09:22）

### 买点（按阶段）
| 阶段 | 买点 | 出处 |
|---|---|---|
| 热启动 | 后排依次炸板后，第 4 名一炸就低吸（前排炸板低吸） | 稿 02:59 |
| 热启动 | 竞价报巨量（分歧竞价解决完）、开盘秒板 | 稿 04:30 |
| 热启动 | 中军趋势容量票、300/688 弹性标、ETF（大题材/牛市参与弹性最大的标的） | 稿 05:08、06:21、07:43 |
| 高潮 | 竞价三一选同题材/同梯队/两市最强 | 稿 08:41 |
| 分化 | 分化必有回流：低吸核心票/低位核心票 | 稿 10:15、11:21 |
| 分歧 | 次日反包（高开转一致）→ 直接上龙头（分歧买龙） | 稿 14:21、15:19 |
| 分歧 | 温和断板高位横盘 → 做低位补涨 | 稿 15:01 |
| 二波 | 冰点反核：只做第一个反核上板的票 | 稿 19:40 |
| 二波 | 冰点买龙：弱无可弱只能转强的临界点上买龙 | 稿 21:39 |

### 卖点
- **不买"第九个"**：竞价七八个一字时能买到的已是后排，开盘秒板盘中必炸（稿 00:57、03:53）
- **早盘最先炸板的不接**（稿 02:00）
- **高潮 = 强无可强只能转弱** → 高潮就是卖点（稿 19:13）
- **分歧日竞价金额排两市前列的中高位"强票"** = 假强 → 回避（稿 11:38）
- **爆量次日低开 = 不及预期** → 第一时间想办法出去，拉升都是出局机会（稿 13:41）
- **分化期汰弱**：今天不封板 = 自己认输 → 直接出；水下票等题材回流、拉升减仓出局（稿 10:53、11:15）
- **龙头断板次日核按** → 退潮：冲高出局、降仓、清仓（稿 15:39）
- **退潮期**：撤退龙打高度是诱多（主力制造噱头出货）；用利润垫跑，不开新仓；弱砍强留（稿 17:07、17:35、17:45）
- **反核后没持续性/次日继续低开/整体走弱** → 最后的出局点（稿 20:42）
- **空间板压制**：高度票突破不了空间板就会被搞（稿 16:47）

## 关键规则与数字

1. **热启动一字数量**：竞价 6~10 个一字（稿 00:50）；买到即排第九（稿 01:00）
2. **封单衰减示例**：10 亿 → 5 亿 → 3 亿 → 1 亿/大几千万，后面的封不住就炸（稿 01:13）
3. **竞价三一的量化标准**：竞价换手/竞价金额两市前三（稿 04:48）
4. **涨停家数递减**：51 家 → 27 家 → 23 家 = 有掉队，做卡位晋级（稿 10:25）
5. **二波超跌幅度**：一般 20%~30% 调整到位；天地板下来可能 30%~40%（稿 18:51）
6. **反核纪律**：只做第一，不做跟风不做后排；反核时一般只有 1 个（最多 2 个）最亮的仔（稿 19:40、19:53）
7. **短线四排序**：逻辑 > 情绪 > 成本 > 技术（稿 09:33）
8. **工具预告**（本集未展开）：翘板五原则（稿 19:36）、顶部信号线（稿 17:51）、第一顺位（稿 03:45）、高阶地天参与（稿 16:01）
9. **回光返照龙** = 题材最后一棒：大资金搞高度票/地天，掩护趋势大票跌停板出货（稿 20:17、20:35）

## 案例分析

> 以下实例均为视频录制时点（2024-2025年）的市场个案，**可复用的是方法而非结论**。

- **数据港 vs 浙大网新（前排判定）**：数据港竞价封单 20 多亿、盘中还有十多亿 > 浙大网新 9 亿；浙大网新先炸 = 弱，炸板不能接（稿 01:35）
- **"第 4 名"排序实战**：新时达、润建确认不会开板，某 AI 机器人票竞价仅 3 个多亿最易开板但扛到最后 → 排第三 = 当天最佳低接目标（稿 03:06）
- **新炬网络（前排炸板低吸）**：DeepSeek 启动第一天，指数大跌把前排带开 → 上车逻辑成立（稿 05:14）
- **拓维信息（趋势容量中军）**：走出一大波（稿 05:43）
- **每日互动（300 弹性标）**：2/5-2/6 两个一字后炸板秒板继续拉；爆量高开转一致是买点，次日高开低走则无买点（稿 05:55、06:30）
- **银之杰（924 行情 20cm 龙头）**：9/20 前后爆量高开即买点，9/24 下杀仍是上车点；UP 主熟人千万级进场、3000 多万出场（稿 07:05）
- **科创板 ETF**：924 行情 20cm 涨停——不会选股就买 ETF（稿 07:49）
- **美格智能 vs 梦网科技（换手优于一字）**：一字上去的见顶就没；换手的多走两个板后才被杭钢用更硬逻辑卡掉（稿 09:13）
- **威派格（分歧期回避中高位）**：位置尴尬+空间压制，直接跌停（稿 12:13）
- **杭钢股份（龙头爆量与反核）**：爆量次日高开表态→下杀释放风险→转一致；龙头给机会直接上龙头；二波反核做的也是它（稿 13:09、14:30、21:11）
- **宁波建工（一字首开模式）**：尾盘砸盘开板但承接住 = 模式买点（哪怕吃面也是买点）；次日低开则拉升出局（稿 13:14）
- **东华软件（低位补涨/低位核心票）**：分歧买龙上杭钢、补涨做东华；龙头 A 杀它也能走一两个板（稿 11:21、15:15）
- **杭齿前进（退潮期空间压制）**：到上方压力位，突破空间板有难度（稿 16:58）
