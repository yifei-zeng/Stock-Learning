## 核心观点

1. **突破来自方法与工具使用上的突破**：把盘面设置好、并理解为什么这么设置，才能提升看盘效率，盘中异动"发生了什么"才能被及时捕捉（稿 00:07、00:16、00:19）
2. **看盘界面应分四块搭建**：①指数/题材板块 ②大局观+情绪标 ③连板梯队+沪深A股全市场 ④分时图/日K/盘口/短线精灵（稿 01:45、06:37、08:33）
3. **版面要"锁定同步"**：栏目必须保证左右/上下滑动时一起联动，否则要删掉重做，用左插入/右插入/上插入/下插入控制分区（稿 07:30、07:45、07:53）
4. **信息要有取舍**：所有信息全勾会变成"噪声"（借用通信概念），要通过修改参数把噪声降到最低，同时保留关键信号（稿 15:15、15:21、15:26）
5. **排序是核心动作**：自选/情绪标/动态板块均可点击表头做正排序、逆排序、涨幅靠前、跌幅靠前（稿 04:58、13:47、14:06）
6. **工具要分场景**：同花顺做全市场看盘与盘中异动，通达信只用于看竞价，开盘啦看情绪+龙虎榜+个股净额时间轴（稿 33:28、35:27、35:37）— 均为 UP 主个人习惯
7. **每日必做的维护动作**：动态板块/反包筛选、连板梯队要**每天收盘后刷新**，否则不出票（稿 26:03、28:17、32:47）

## 行情判断

- **板块涨幅榜读法**：竞价时看谁涨幅靠前/靠后，判断当天可能哪个方向；银行、证券这类关键指数属于"维护盘面"角色，要一并观察（稿 02:50、03:02）
- **同花顺一级行业 vs 一级板块成分股不同**，同样"五个涨停"数值会不一样；如通用设备板块范围更宽泛，相关概念股被归到通用设备里，涨停数量会偏多（稿 02:06、02:19、02:25）— **实例为录制时点个案**
- **竞价成交金额的含义随情绪阶段翻转**：上升期竞价成交多可能是抢筹信号；退潮期竞价成交多可能是逃跑资金/抢跑，是分歧大的表现（稿 12:36、12:39、34:29、34:37）
- **未匹配金额两端看方向**：上亿/大几千万级通常对应涨停或跌停的封单；中间小额只是买一卖一残余资金，无方向含义（稿 14:16、14:28、14:33）
- **情绪温度的取样方法（竞价三段截图）**：9:15、9:20、9:25 各截一张图，对比封单大小变化与"1亿以上封单家数"变化，判断情绪变化（稿 34:04、34:07、34:10、34:16）— 属通用方法，截图时点为 UP 主习惯
- **连板梯队规模即情绪强度的一个侧面**：录制时处于退潮期，四板以上仅三只；若情绪特别好，四板以上可能二三十只（稿 05:20、05:27）— **实例为录制时点个案**
- **动态板块的核心用途**：能从连板梯队里筛出**反包意愿很强**的票（稿 30:30、30:36）

## 操作逻辑（选股·买点·卖点）

> 本篇为工具设置类内容，不构成买卖操作建议；以下是原稿中与"如何筛票/如何观察"相关的方法性内容。

### 选股（动态板块筛选语句，均为同花顺个人配置）

| 板块 | 条件构成 | 出处 |
|---|---|---|
| 炸板 | 炸板 且 排除ST | 稿 25:44、25:49 |
| **反包** | 非ST；三日内涨停次数=2 **或** 四日内涨停次数=2；前一交易日未涨停（英文分号连接） | 稿 27:18、27:32、27:38、27:47 |
| 跌停 | 跌停 且 非ST（英文分号） | 稿 28:35、28:45 |
| 断板 | 非ST；昨日涨停；今日未涨停 | 稿 28:50、28:56、29:01 |
| 四板及以上 | 涨停 且 连板数>3 | 稿 29:11、29:13 |
| 七板及以上 | 涨停 且 连板数≥7（并重命名为"七板加"、可设颜色） | 稿 29:26、30:02、29:49 |
| 连板梯队 | 六板/五板/四板/三板/二板/一板 分别单列 | 稿 30:04、30:09 |

- **反包定义**：近两天内涨停过、昨天没涨停、今天又涨停（稿 25:55、25:58、26:00）
- **反包筛选对时间极敏感**：必须当天收盘后按此方式筛；释放/隔天再开就会不出票（稿 26:16、26:26、28:17、28:28）
- **UP 主自评该语句覆盖度**：约 99.9% 的个股情况，只有极少数在范围之外（稿 26:52、26:55、26:59）— 个人经验值，未验证
- 手动设置四板/三板/二板也可以，但麻烦，UP 主一律用动态板块（稿 25:33、25:41、25:42）

### 观察点（非买卖点）

- **隔夜单**：竞价阶段的跌停封单金额可作隔夜单强弱参考（稿 33:50、33:52）— 实例数值见"待确认项"
- **大单买入>500万** = 盘中有票在被翘板，且该信号比"打开跌停"信号更早（稿 16:31、16:37、16:44）
- **未匹配金额快速排序**可快速筛出涨跌停封单（稿 14:16、14:18）
- **首次涨停时间**列用于早盘看封板梯队顺序（稿 31:38、31:45）
- **主力净额时间轴**（开盘啦）：可看哪个阶段主力在吃货、哪个阶段买卖力量对比逆转；尾盘净流出≠主力没干活，可能只是卖方力量更大（稿 36:31、36:40、36:46、36:51）— 属通用资金流解读方法

## 关键规则与数字

### 看盘界面 / 表头

1. **看盘界面八块分区**，用左/右/上/下插入切分；跨栏必须同步联动，否则删掉重做（稿 07:00、07:30、07:45、07:53）
2. **必须保证四个表头露出**：涨幅、竞价涨幅、竞价金额、未匹配、涨速（即"四个"含涨速共五项，原稿计数与列举不一致）（稿 09:22、09:24、09:25）
3. **表头顺序**：代码、名称 → 三个静态项（竞价涨幅等）放前 → 涨幅放第4位 → 早盘竞价金额 → 未匹配金额 → 4分钟涨速（稿 11:03、11:09、12:04、12:10、12:11、12:23、14:50）
4. **动态板块/自选方案表头同步**：在一个界面设好基础表头后，右键"同步自选方案"可一键同步到所有方案，无需逐个调（稿 30:52、30:54、32:32、32:38）
5. **唤醒快捷键**：修改页面信息里设唤醒键（UP 主用"点13"，因点10/点12/点11被占用或重复）（稿 10:16、10:27、10:32、10:34、10:38、10:40）
6. **多版面快捷键**：Alt+2/3/4 对应 2/3/4 版面，**最多只支持 2/4/6 六个版面**；UP 主一般用 3 个版面（稿 37:54、38:12、38:14）
7. **同花顺版本差异**：不同版本字段名不同（如"竞价涨幅"与"竞价涨幅%"），搜到多个结果时任选其一并改名即可（稿 11:23、11:35、12:16、12:19）

### 短线精灵参数

8. **监控范围**：全部A股；剔除 ST 与退市整理板、当天新股、北交所；科创板与创业板保留（稿 15:38、15:41、15:45、15:47、15:48）
9. **默认阈值 1万手 / 500万**（原稿"1万首"）（稿 15:54）
10. **只选四类信号**：大单买入、大单卖出、涨停封板、打开涨停（稿 16:02、16:04、16:06、16:08）
11. **"打开跌停"不勾的理由**：有意义的跌停打开一般伴随 500万以上金额，等信号出现时 500万已抄完底，信号滞后（稿 16:20、16:24、16:28、16:31）
12. **尾盘竞价/盘中区间划分**：情绪、4板及以上、3板、2板、1板、全部，间距按当日股票数量每天调（稿 17:54、17:56、17:59、18:00、18:02、18:05）

### 指标代码与坐标

13. **分时/日K 代码出问题 → 一键恢复默认**（分时在"更多设置→修改分时走势"；日K有"修改均线"与"修改参数"两个入口）（稿 19:25、22:41、22:45、23:28）
14. **分时均线不显示的解法**：第 59 行附近（原稿"如59行"）报错时，加**英文小括号**（一定是英文括号）即可显示概念、盘中涨跌停家数等（稿 20:41、20:45、20:48、20:55、21:00、21:04）
15. **加括号的副作用**：该界面均线消失，但点进个股详情均线仍在，UP 主认为影响不大；bug 未解决（稿 21:58、22:02、22:09、22:15）
16. **分时界面的涨停/跌停家数统计含 ST，不够准确**；去除 ST 的家数要看另一个工具（稿 21:12、21:18、21:34）
17. **横坐标可调**：更多设置里改 0.6/0.8/0.2/0.1 等数值，数值越大元素越往右移；改坏了直接恢复默认重来（稿 24:08、24:16、24:29、24:48、24:58、25:06）
18. **Tab 键**可显示/切换均线（稿 23:33、25:19）

### 竞价（通达信）

19. **通达信只用于看竞价**，栏目：代码、名称、细分行业、涨幅、封单额、开盘换手、开盘金额，其余不要（稿 33:30、33:37、34:56、35:03）
20. **封单额 = 涨停封单 + 跌停封单**，竞价阶段看隔夜单（稿 33:45、33:50、33:52）
21. **开盘换手** = 竞价阶段成交量占个股的比例（稿 34:23、34:26）
22. **开盘金额** = 竞价成交的金额（早盘竞价金额同义）（稿 12:25、34:40）
23. **封单是实时变化的**，故要 9:15 / 9:20 / 9:25 三次截图，对比封单大小与**1亿以上封单家数**的变化（稿 33:59、34:04、34:07、34:16）

### L2 与开盘啦

24. **主力净额（盘中流入净额）需 L2 才能看到**（稿 31:31、31:34）
25. **L2 费用**：UP 主口述"每年两百多，298 是基础版，有时打折两百块左右"，属个人陈述，价格以官方为准（稿 37:07、37:10、37:12）
26. **大单分时金额**：L2 → Level2特色指标 → 分时指标 → 大单金额，添加后挪到舒适位置（稿 37:28、37:32、37:41）
27. **开盘啦需配合模拟器使用**（UP 主用雷电），在软件中心搜索下载（稿 35:13、35:19、35:21、35:25）— 个人习惯

## 案例分析

> **以下盘面数值均为视频录制时点的个案快照，仅用于说明字段读法，可复用的是方法而非结论。**

- **未匹配金额读法**：某票（原稿"东华软件"，[13:52]）竞价结束时买盘未匹配 **3.3 亿**；另一票（原稿"梦网科技"，[14:09]）卖一未匹配 **4.23 亿**（跌停封单）。方法是：在两市排序里用未匹配金额找两端极值（稿 13:01、13:27、13:55、14:11、14:16）
- **中间值不算方向**：中国能建卖一四千多万属盘子偏大导致资金多，日海智能是明显跌停封单——说明只看两端（稿 14:35、14:41、14:43）
- **"某软件跌停封单排名第一 120 多亿"**：录制时点隔夜单实例，原稿表述含错字、指代不明（稿 33:53）→ 见待确认项
- **竞价成交额排序实例**：一票竞价成交 1 亿 vs 另一票 3000 万；竞价成交多在上升期可能是抢筹（稿 12:32、12:35、12:36）
- **情绪标的容量**：UP 主情绪标区积累约四百个历史票；录制日退潮期四板以上仅 3 只（稿 04:33、05:20）— 数量表述见待确认项
- **权重护盘观察**：宁德时代、东方财富、贵州茅台常驻，权重护盘时能明显感到高开；比亚迪因形态好被放入（稿 03:51、03:59、04:06）— 属录制时点选样
- **A50 与离岸人民币汇率**：A50 是新加坡交易的期货品种，对 A股有一定价格发现与引导作用，故常驻页面（稿 03:38、03:41、03:43、03:46）
- **净额时间轴读法实例**（原稿"中文互联"，[35:48]）：尾盘杀跌但主力仍净流入 → 往后看好；从炸板开始主力净流出 → 说明散户承接多；炸板区间主力净进约 3 亿；从最低点到上板主力净进约 2 亿；炸板之前是大吃货、净进 6 亿多（稿 35:56、36:00、36:03、36:09、36:25、36:28、36:53、36:57）— 个股名称存疑，数值属录制时点
- **竞价换手读法**：竞价换手很大时，上升期可能是抢筹，退潮期可能是抢跑，是分歧大的表现（稿 34:29、34:34、34:37）
