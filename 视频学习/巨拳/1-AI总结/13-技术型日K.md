## 核心观点

1. **本篇定位纯基础扫盲**：内容是技术型日K的图形识别与各图预期，属"三个面"（基本面、技术面、资金面）里的技术面，被 UP主安排在最前面讲，因为它最容易混淆（稿 00:34、01:03、01:10）。
2. **知识分三层**：单日K五类 → 日K组合五类 → 趋势图形五类，层层叠加（稿 39:56–42:14）。
3. **各图都有"预期"方向**：UP主明确按"看到某类看涨、看到某类看跌"来组织，但强调这只是辅助（稿 15:03、16:11）。
4. **最重要的态度声明**：日K组合只是提高成功率的手段之一，和"只打龙头""只做低位板"一样是概率工具；单纯看一个图形去做交易"你完蛋了"（稿 16:23–17:00）。
5. **趋势由小级别日K堆叠而成**：反复出现同一类组合（如多方炮），股价就沿那个方向走，小级别组合成大级别即形成趋势（稿 32:48–33:29、41:41–41:50）。
6. 本篇全程手绘，未使用实盘截图，UP主留了两个作业让观众自行对照（稿 42:39–43:08）。

## 行情判断

### 单日K五类（含各自含义）
| 类别 | 形态 | 含义/前提 |
|---|---|---|
| 阳线 | 收盘价高于开盘价为红K线；横线的上下位置即开盘价与收盘价，中间怎么走不管（稿 03:32、04:36） | 开盘十元收十一点即为10%涨停阳线（主板涨幅上限10个点，创业板20个点）（稿 03:05、03:21） |
| 连板 | 两个及以上连续涨停 | 二连板、三连板、四连板，向下同理为连续跌停（稿 05:32–06:10、06:56） |
| 阴线 | 收盘价低于开盘价为绿K线 | 十元跌到九元即10%跌停（稿 06:12–06:55） |
| 长上影／长下影 | 盘中冲到（或砸到）某个价位后回到开盘价附近 | 长上影＝冲高回落，长下影＝下杀跌停后翘板回平盘；关键是"曾经到过"而不是"收在那里"（稿 07:59–10:51） |
| 十字星 | 盘中上下震荡，同时有长上影与长下影，收在开盘价附近（稿 10:12–10:32） | — |
| 一字板／T字板 | 次日直接跳空到涨停开盘且未炸板，为一字板；炸开过涨停板为T字板（稿 11:06–12:05） | 最原始的日K理论里没有涨停板概念，这是我们市场特有的（稿 12:09–12:18） |
| 缺口 | 因外部因素或业绩导致跳空高开／低开，跳空的幅度即缺口（稿 12:22–13:24） | 分向上缺口、向下缺口 |

### 组合五类及其预期
| 组合 | 形态 | 预期 |
|---|---|---|
| 阳包阴 | 次日阳线完全反包前一日阴线 | 看涨（稿 15:16–15:53） |
| 阴包阳 | 次日阴线明显包住前一日阳线（可跳空向下／高开低走／低开） | 看跌（稿 17:02–17:29） |
| N字形反包 | 涨停→调整两天→再涨停；反向则为倒N字（向下反包） | 调整未跌破前一个涨停位置则看涨（稿 17:37–20:42） |
| 多方炮 | 涨停→明显调整→再涨停包回 | 看涨；最后一根必须包掉中间阴线，力度更强（稿 21:12–22:26） |
| 空方炮 | 大跌→大涨→再大跌 | 看跌（稿 22:27–22:54） |
| 叠叠多方炮／空方炮 | 涨停跌停涨停跌停再涨停，动作重复两次 | 实战很少用（稿 23:55–24:35） |
| 红三兵 | 连续三根上涨的红K线（低开高走的红K不算） | 看涨（稿 24:40–25:16） |
| 三只乌鸦 | 连续三根下跌的阴线 | 看跌（稿 25:20–25:38） |

### 趋势图形的预期
- 双底 / 双顶：两个位置大致相当的低点（或高点）；双底突破前高后回踩为"双底确认"，看涨；双顶反过来看跌（稿 34:28–36:01）。
- 三底 / 三顶：三次对同一压力位向上突破，突破后有回踩（稿 36:02–36:42）。
- N字底 / N字顶；头肩底 / 头肩顶（稿 36:45–38:33）。
- 圆弧底 / 圆弧顶：走势整体平滑，实战少见，多数是复杂N字底、双底、三底或头肩底；圆弧底反弹到压力位回踩后再上看涨（稿 38:46–39:51）。
- 双底、三底、N字底这一类自成一族，UP主统称"复合底"（稿 38:34–38:43）。

## 操作逻辑（选股·买点·卖点）

本篇是基础图形课，**UP主未给出任何买点、卖点规则**，只留下以下几条与操作有关的表述（均为方法论描述，不含指向性意见）：

- **图形的定位是"辅助"**：只打龙头股提高成功概率、只做低位板提高安全度、只打阳包阴提高成功率——多种同类因素叠加最终让成功率上升，这才是目的；看到阳包阴不等于一定赚钱（稿 16:23–17:00）。
- **最后一根K线代表资金的进攻方向**：组合走势里，最后收盘那根如果是有反包力度的涨停大阳线即为多方炮，如果是阴线则看跌（稿 23:36–23:52）。
- **要理解含义而不是背图形**：涨停—跌停—涨停—跌停这类剧烈振幅背后是强烈洗盘，把自己代入持仓者（前一天打板、次日跌停割肉、第三天又涨停）就能体会洗盘的作用（稿 23:02–23:35）。
- **长上影在实战中用得最多**：UP主自述做弱转强时最常使用的是长上影，但这属于更后面的内容，本篇只讲形态含义（稿 07:44–07:57、11:01）。
- **两个作业**（稿 42:39–43:08）：① 自己去找板块，把上述图形一一对上实例；② 想一个能更好解释压力与支撑互为转变的例子。

## 关键规则与数字

- **涨跌幅上限**：主板 10%，创业板 20%（稿 03:21–03:27）。
- **K线周期**：日K、周K、月K、年K，按不同时间周期定义；日常以日K为主（稿 02:06–02:15）。
- **竞价与开盘**：9:25 出竞价，9:30 出开盘价（稿 02:19–02:32）。
- **N加几的计数规则**：涨停后只要不是连续涨停都算调整（可小跌、可横盘、可微涨），隔一天反包为 N加一，隔两天为 N加二；连续两天涨停就是二连板（稿 18:40–19:58）。
- **多方炮的强度判据**：第三根涨停最好包掉中间的阴线，反包力度更强（稿 22:13–22:26）。
- **压力与支撑的转换规则**：区间高点在被有效突破前是压力位，有效突破并回踩后变成支撑位；向下同理（稿 26:26–27:42、32:20–32:35）。
- **有效突破的条件**：UP主用两个类比说明——运动员成绩突破后要保持不下滑，台阶本身要够硬；站不住的突破不算数（稿 31:45–32:19）。
- **空方炮作业的数字**：UP主印象中，4—6 月科技（CPO、PCB、半导体）在高位震荡阶段出现了至少四五根空方炮图形（稿 33:36–34:12）。

> 本篇基本为手绘演示，实盘案例极少，以下两条是视频中提到的盘面呼应。
