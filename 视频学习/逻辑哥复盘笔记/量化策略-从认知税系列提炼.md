# 量化策略 · 从《认知税系列》12 篇提炼

> 来源：B站 UP主「逻辑哥复盘笔记」《认知税系列》01–12 篇（逐字稿总结见 `1-AI总结/`）
> 本文件把 12 篇里的**方法论框架**转写成可编码、可回测的规则与参数，不包含任何具体买卖标的。
> **免责：UP主在多篇声明"仅作为个人梳理，不作为投资建议"。本策略是方法论提炼，不构成对任何人的买卖建议、不承诺收益。**
> 写作原则：每条规则标注【来源篇目】；UP主口述的经验阈值标注「经验值·需按自身校准」；语音识别不确定处如实标注「不确定」。

## 0. 一句话定位

视频反复强调的一句话是「**散户缺的不是策略，而是系统**」「策略回答买什么，系统回答每一步先做什么」【11】。所以下面不只是一组买卖信号，而是一条**从市场环境过滤 → 标的池 → 买入 → 仓位 → 止损 → 止盈 → 复盘迭代**的完整决策链。每一步都写成可判定的布尔/数值条件，量化落地时可直接转成代码。

**先决条件（第 3 篇「定位」）：** 本策略主模板默认按 **波段趋势** 打法编写（它是三种打法里最可量化的一套：「基本面为锚、技术面为帆」，且只需每日复盘、不需全程盯盘）。若你定位是超短线或长线，需替换第 4、5 节对应的模块（见附录 A）。

## 1. 市场环境过滤层（Regime Filter）——决定「今天能不能做」

作用：**先排除不该做的行情**，不是用来预测涨跌。三条过滤器同时满足才进入后续选股。

### 1.1 牛市/趋势三信号【01】
| 信号 | 量化口径 | 方向 |
|---|---|---|
| 成交额 | 沪深两市日成交额较 N 日均量**创新高 / 温和放大** | 放量=火 |
| 银证转账 | 存款向证券账户净流入（月度） | 净流入=有钱进来 |
| 开户数 | 券商新增开户激增（月度） | 激增=有人气 |

> **反向即离场信号**：开户数掉、成交额缩、银证转账不再流入 → 触发「牛市还在不在」检查，降档。【01】
> 注意：这是趋势/行情级别的慢变量，逐日只能观测到成交额；开户数、银证转账为月度数据，作为**月度再确认**。

### 1.2 均线趋势过滤【12】
| 规则 | 量化条件 | 结论 |
|---|---|---|
| 牛熊分界 | 收盘价 **在年线（MA250）上方** | 只考虑做多 |
| 牛熊分界 | 收盘价在年线下方 | 观望（不做多） |
| 多头排列 | MA5 > MA20 > MA60，且短长均线距离**持续扩大** | 偏进攻 |
| 缠绕 | 均线反复交叉、方向不明 | **震荡市，明确停用** |

> 均线的正确定位是「**显示器，不是信号发生器**」——它只负责过滤趋势与参考仓位，不直接生成买卖信号【12】。**只用 1~2 根均线**（一根看节奏 MA20，一根看方向年线），超过 3 根属于「同源数据重复计数」，会产生虚假安全感【12】。

### 1.3 主线四段论——只在「发酵期」参与【09】
任何一段主线行情都走「启动 → 发酵 → 高潮 → 退潮」四阶段。**只在 ②发酵期 建仓**：逻辑已清晰 + 情绪未极端，两个条件同时成立。

| 阶段 | 量化特征 | 动作 |
|---|---|---|
| ①启动 | 温和放量、不爆量，少数标的先动 | 只建**观察名单**，不重仓 |
| **②发酵** | 量能持续放大但不极端，龙头确立、跟风扩散成**梯队** | ✅ **唯一可介入区** |
| ③高潮 | 天量频出、换手剧烈、不看盘的人也来问 | 不新增买盘 |
| ④退潮 | 量能萎缩（没人接）、天量滞涨（有人出货） | 不参与，反弹是离场不是进场 |

**主线确认三信号（缺一条最多算「今天涨得不错」，不算主线）【09】：**
1. 有**龙头**（大市值票走出强度 / 短线高度票突破压制位）
2. 有**梯队**（龙头之外形成 5-4-3-2-1 的完整梯队）
3. 有**持续性**（连续 2~3 天保持活跃，不要求天天第一）

**题材三级（决定持有方式，避免级别错配）【09】：**
| 级别 | 驱动 | 持续时间 | 参与方式 |
|---|---|---|---|
| 政策级 | 国家政策/重大改革 | 数月+ | 分段波段 |
| 产业级 | 产业趋势/技术周期 | 数月至数年 | 反复跟踪 |
| 事件级 | 单一事件/短期消息 | 数天至数周 | 快进快出、不留恋 |

> **判据口诀**：量能萎缩 = 没人接；天量滞涨 = 有人出货；「上涨若靠的是原来那批票、没有新领涨新跟风，那就结束」【09】。

## 2. 标的池（Universe）——先排雷、再看方向

> 「先排雷、再看方向」【11】。标的池收窄到 **50~100 只**（经验值），「池子再大等于没有池子」。

### 2.1 财报排雷（来自第 8 篇，全部转成阈值）
**第 0 步：审计意见**——必须是**标准无保留意见**，否则直接卡掉，后续全不看【08】。

| # | 指标 | 量化条件 | 命中即卡掉 |
|---|---|---|---|
| 1 | 净现比 = 经营现金流 ÷ 净利润 | **持续 < 1**（3 年趋势） | ✅ 卡掉 |
| 2 | 应收账款增速 vs 营收增速 | 应收增速**远高于**营收（例：应收 +80%） | ✅ 卡掉 |
| 3 | 应收账款周转天数 | **>120 天有鬼**；<30 天优秀（经验值） | ✅ >120 卡掉 |
| 4 | 存货增速 vs 营收增速 | 存货比营收涨得还快 | ✅ 卡掉 |
| 5 | 有息负债 vs 账上现金 | **大存大贷**（账上有钱仍大量借款） | ✅ 卡掉 |
| 6 | 商誉 ÷ 净资产 | 占比高（尤其靠单一个人 IP/明星的公司） | ✅ 卡掉 |
| 7 | 流动比率 = 流动资产 ÷ 流动负债 | 长期 < 1 | ✅ 卡掉 |
| 8 | 资产负债率 | 制造业 30%~40% 正常、**60%+ 有问题**（行业差异大，银行地产天然高） | ✅ 超行业基准卡掉 |
| 9 | 非经常性损益占比 | 卖资产/补贴/退税撑利润 → 用**扣非净利润** | ✅ 靠非经常性损益盈利卡掉 |
| 10 | ROE | 长期 > 15% 较优，看 5~10 年（此为长线标准，波段作参考） | — |

**看 3 年趋势、对比同行，不看单点**；时间节点重点盯 1、4、7、10 四个月（财报季）【08】。
> 核心判据：**净利润是观点，现金流是事实**——净现比持续 <1，利润就是账面数字【08】。

### 2.2 流动性/股性底线（来自第 2 篇「无股性无情绪无资金无催化——不要聊」）
| 字段 | 量化条件（经验值·需校准） |
|---|---|
| 市值 | 设下限（排除流动性过差的微盘） |
| 换手率/成交额 | 设下限，保证**股性活跃**、能进出 |
| 板块 | 只保留主线方向内的板块（对应 1.3 节） |
| 基本面底线 | 已通过 2.1 排雷 |

### 2.3 剔出条件
- 财报触发 2.1 任一「卡掉」项 → 移出标的池
- 跌破标的池定义的市值/流动性下限 → 移出
- 主线退潮（进入 ④退潮）→ 该方向整体移出观察

## 3. 买入信号（Entry）——波段趋势版【02/03/05/09/12】

> 买入条件必须是「可判别硬条件」。**检验法：拿给完全不懂股票的人看，他看完仍不知道买不买 = 不合格**【11】。
> 满足下面 **A 组（择时）任一 + B 组（验证）全部**，才触发买入。

### 3.1 A 组：择时形态（任一满足）
| 编号 | 形态 | 量化定义 |
|---|---|---|
| A1 | **启动突破** | 日线级别 + 周线级别**双突破**（收盘放量突破前高/关键压力位）【02】 |
| A2 | **双底买点** | 日线级别双底：第二只脚**不创新低**、价格企稳（只做日线级别，不做月线/分钟级）【02】 |
| A3 | **回踩不破** | 回踩 MA20（生命线）不破，随后放量收回【11 买入条件举例，具体参数「不确定」】 |
| A4 | **十字星止跌** | 十字星后次日**放量约 1.5 倍阳线** → 疑似止跌点【05】 |

### 3.2 B 组：验证条件（全部满足）
| 编号 | 验证项 | 量化定义 |
|---|---|---|
| B1 | 阶段过滤 | 该方向处于主线**②发酵期**（1.3 节三信号齐备） |
| B2 | 趋势过滤 | 标的在**年线上方**、MA5>MA20>MA60 多头排列（1.2 节） |
| B3 | 量价验证 | 价涨**量增**（健康）；价涨量缩=动能衰竭(不买)；放量滞涨=顶部(不买)【02/12】 |
| B4 | 池内+排雷 | 标的在标的池内且通过 2.1 排雷 |
| B5 | 有止损位 | 已按第 5 节定好止损位（先算风险再进场） |

### 3.3 买入前最后一道：写反向观点【05】
下单前书面回答（写不出来 = 没想清楚 = 不做）：
1. 我可能会错，错在哪？
2. 判断依据是什么？
3. 什么信号出现证明我错了？
4. 最坏会亏多少？

## 4. 仓位管理（Position Sizing）【06】

> 第一条铁律：**单笔最大亏损 ≤ 总资金 2%**；月度累计亏损上限 6%（四条不可谈判规则中已展开的两条）【04/06】。
> 期望值 = 胜率×平均盈利 − 败率×平均亏损；高胜率≠赚钱，期望值为正才赚钱。**仓位管理只负责让你活到期望值兑现的那一天**【06】。

### 4.1 下单量：固定分数法（风险百分比，新手首选）
```
可买股数 = (总资金 × 单笔风险 2%) ÷ (入场价 − 止损价)
占用资金 = 可买股数 × 入场价
```
> 止损位越近买得越多，止损位越远买得越少——**同一笔 2% 风险，先有止损位，才谈买多少**【06】。

### 4.2 仓位硬约束（经验值·需按资金体量校准）
| 约束 | 数值 |
|---|---|
| 单笔最大亏损 | ≤ 总资金 **2%** |
| 月度累计亏损熔断 | **6%**（到线当月停手） |
| 单票最大仓位 | ≤ **10%**（稳健散户示例【04】） |
| 最大同时持仓 | ≤ **4 只**（3 只足够）【06】 |
| 最低现金比例 | 永远保留 **10%~20%** 现金【06】 |
| 加仓 | 仅**浮盈**加仓，金字塔式（每次加仓量递减、次数 ≤ 2）【06】 |

### 4.3 三层仓位结构【06】
| 层 | 作用 | 备注 |
|---|---|---|
| 底仓 | 长期不动，跟上市场 | 可换为波段 |
| 机动仓 | 主线波段、事件驱动，创造超额 | 本策略主要操作层 |
| 现金 | 永远保留 10%~20%，是你的选择权 | — |

### 4.4 加减仓规则【06】
- **加仓唯一通行证 = 浮盈**；金字塔加仓（首笔 1 → 2 → 3，每次递减，≤2 次）；倒金字塔补仓（越跌越买越重）禁止。
- **减仓四条触发**（写死）：①到止损位（不问理由不改线）；②买入逻辑破坏（不管盈亏都走）；③到目标位分批止盈，**第一批先减一半**；④单票仓位超限，超出部分无条件减。

### 4.5 熔断/停手线【04/06】
- 连续**止损 3 次**（哪怕一周内、两天内）→ 立即停手复盘，不交易。
- 账户回撤 10% → 停手 3 天；连续三个月亏损 >15% → 判定当前市场不适合你，暂停。
- 半凯利：若用凯利公式，**仓位砍半**使用（因为你并不确知自己的真实胜率与盈亏比）【06】。

## 5. 止损（Stop Loss）【04】

> 止损不是判断对错，而是**控制你下一笔的规模**。核心是「把规则写纸贴屏幕旁，让规则替情绪决策」。

从九种止损里，波段趋势**主选 2~3 种**（新手先固定百分比，进阶加均线/前低）：

| 规则 | 量化条件 | 优先级 |
|---|---|---|
| **资金管理止损（必选）** | 单笔亏损达总资金 2% → 无条件离场 | ⭐最高 |
| **前低止损** | 跌破技术前低/近期低点 → 离场（个股**不做左侧抄底**）【02】 | 高 |
| **均线止损** | 跌破 MA20（生命线）→ 走 | 高 |
| 固定百分比 | 亏 8%~10% 立即走（嫌高用 -5%~-6%）（经验值） | 兜底 |
| 逻辑止损 | 买入逻辑被破坏（如主线退潮、财报暴雷）→ 不管盈亏都走 | 高 |
| 情绪止损 | 状态不对（极致焦虑）→ 清掉，不碰 | 兜底 |

> 「一天最多止损 N 次，超过即当日停手」——N 由你自己写死【11】。

## 6. 止盈（Take Profit）【02/04】

> 止盈的本质是**学会放弃**。九种里主选 1~2 种，**不要同时用五种**。

| 规则 | 量化定义 |
|---|---|
| **分批止盈（首选）** | 仓位分 3 份，浮盈 **+10% / +20% / +30%** 各卖一份（经验值）；先把本钱拿回来，让子弹飞【02/04】 |
| 目标止盈 | 到 **+20%** 就收手（新人可只设这一条）【04】 |
| 动态跟踪止盈 | 涨了把止损线提到成本线，再涨再提（例：10 元→10.2 设 10.1→10.5 设 10.3）【04】 |
| 形态止盈 | 突破后跌回颈线即止盈（双底、头肩顶）【04】 |
| **情绪止盈** | 情绪指标读数 >80 预示过热 → 分批减仓；人声鼎沸（所有人都在聊）→ 减【02/04】 |
| 时间止盈 | 拿 3 个月不涨就换（中长线）【04】 |

**减仓信号（量价）【02】:** 价涨量缩 = 动能衰竭；放量滞涨 = 顶部信号。

## 7. 复盘与迭代（Review Loop）【07/04/11】

> 复盘是「审判」，审判对象是**你的决策过程**，不是市场。**没有产出规则 = 还在记账**。

### 7.1 每日：五段式复盘（收盘后 15 分钟内写完）
指数 → 情绪 → 资金 → 计划 → 推演（五段顺序不能改，先客观后主观；模板见 `../我的复盘/每日复盘模板.md`）。

### 7.2 每笔：错误三分法 + 交易日志
| 错误类型 | 定义 | 处理 |
|---|---|---|
| 可避免 | 违反了自己写的规则 | 修纪律 |
| 不可避免 | 规则内正常执行遇系统性下跌 | **不改规则** |
| 系统性 | 规则/策略本身期望值为负 | 改规则 |

日志 5 字段【05】：开仓理由 / 入场价·计划止损·计划止盈 / 当时情绪 / 是否符合规则 / 结果+一句话复盘。
**判断阈值**：同样情况连续亏损 **10 次以上 → 大概率规则问题**；十次错一次 → 规则没大毛病【07】。

### 7.3 迭代频率【11/07】
- 每周：四步周复盘（验证预判 / 主线实况 / 改哪条规则 / 下周观察）
- **每月至少改出一条规则**（这是复盘「出东西」的最低标准）

## 8. 回测与验收协议（Backtest & Validation）【11/12】

策略写好不是结束，**三关全过才算能用**：

| 关卡 | 关键问题 | 量化检验 |
|---|---|---|
| **一致性** | 能不能每次都执行？ | 连续 **20 笔**，有没有一笔是规则之外的 |
| **期望值** | 数学上能否赚钱？ | 胜率×平均盈利 − 败率×平均亏损 **> 0**（高胜率≠赚钱） |
| **样本足够** | 样本够不够？ | 至少 **20~30 笔**实盘/回测；**换到单边下跌、极端情绪环境仍成立吗** |

**防过拟合红线（第 12 篇反复警告）：**
- 均线**只用 1~2 根**，禁止多均线共振（同源重复计数）
- 禁止参数过度优化（「参数调到回撤最优」的实盘表现远差于回测）
- 金叉死叉直接作为信号 = 天然滞后，震荡市反复打脸，**不作为主信号**
- 每个组件写 2~3 条，总共二三十条够用；写多了会选择性执行【11】

## 9. 可编码规则汇总表（一键对照）

> 下表是全文的压缩版，量化落地时可直接映射成信号函数。

| 环节 | 规则 | 量化表达 |
|---|---|---|

## 10. 落地建议（量化实现路径）

1. **先把「定位」填死**（资金能用多久 / 每天盯盘时间 / 能连亏几次 / 性格）——见 `../我的复盘/我的交易系统.md` 组件 1。定位决定你用本模板还是附录 A/B。
2. **先只跑一层信号**：用第 1 节市场过滤 + 第 2 节标的池 + 第 4~6 节仓位止损止盈做**纸面/回测**，不要一次上全部形态（新手从 A2 双底或 A3 回踩 MA20 起步）。
3. **跑满 20 笔再迭代**，每月至少改一条规则；迭代只动「复盘迭代」这一层，不要因为一两笔亏损乱改其他组件。
4. **参数一律先取视频给的默认值**，再按自己的资金体量/交易频率重校准（README 已提示这些是经验阈值，非通用标准）。
