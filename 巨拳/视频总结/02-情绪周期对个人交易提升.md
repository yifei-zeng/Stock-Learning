## 核心观点

1. **周期论必须挂靠时间，不分时间讲周期就是"耍流氓"**。周期分大周期（行业自身周期，从无人问津到人声鼎沸，长则数年）与小周期（情绪周期），这是全文的坐标系（稿 01:16–01:56）。
2. **情绪周期严格分为四个阶段：主跌 → 低位试错 → 主升 → 高位震荡**；下跌中继、首次见底、二次见底是 UP 主自己扩展的"小的"知识点，二波主升在逻辑上仍归在主升范围内（稿 29:56–30:21）。
3. **判断阶段的唯一核心变量是"亏钱效应是否连续"**。不是看指数涨跌幅，而是看亏钱效应是"每天套一批人往下砸"还是"涨一天跌一天"（稿 14:03–14:14、15:08–15:13）。
4. **情绪周期是试出来的，不是看出来的、不是探出来的**。正确姿势是"带着预判去跟随、去试错"，把底部和顶部一个一个试出来，而不是提前下结论（稿 38:42–39:17）。
5. **防守优先于进攻**。之所以从主跌开始讲，是因为"两手理论"的核心是从防守角度学习、先用可控资金介入；"防守才是王道，防不住是没价值的"（稿 07:49–08:47）。
6. **所有大利润都产生于主升阶段**。低位节奏做得好可能只有 10–20 个点，主升做好一波 50 个点很正常；账户里的大利润"没有例外"都出现在市场主升上（稿 21:26–21:56）。
7. **实际操作要"简化、简化再简化"**。三个概念（下跌中继 / 低位试错 / 首次见底）本质上只看一件事：亏钱效应会不会连续（稿 14:59–15:13）。

## 行情判断

### 大周期（行业周期）判断
- 大周期 = 行业自身的周期反转，"涨多了跌、跌多了涨，市场上没有一路阴跌的板块"（稿 04:30–04:46）。
- 锂电池：2020 年白酒带动趋势股赚钱效应 → 扩散到 2021 年新能源汽车、储能 → 2021 年炒锂电池；2021 年 12 月见顶后 98 天跌 40%，直接腰斩，此后阴跌数年；2024 年 9 月见底后板块再创新高（非全部个股，是核心品种如天赐）（稿 02:07–03:56）。
- 海运：2020 年见顶后中远海控一年十几倍（稿 03:59–04:27）。

### 短周期（情绪周期）判断
- 中周期案例：2026 年 4 月 8 日—6 月 25 日创业板指一波主升，最强主线是以 AI 硬件为主的泛科技，这段时间属于短线周期的**主升阶段**——"每一次的调整都是为了更好的上涨"（稿 05:06–05:45）。
- 更短的小周期：7 月 9 日（周四）为启动第一天、周五为启动第二天；从大格局看属于反抽，从周四角度看属于启动（稿 05:58–06:28）。
- 打板资金的分工：启动阶段不打板，接力阶段让接力资金赚钱，做首板的人赚启动的钱（稿 06:32–07:00）。

### 各阶段的识别信号（逐条清单）

| 阶段 | 识别信号 | 出处 |
|---|---|---|
| 主跌 | 无论什么板块都出现**持续性**亏钱效应；多杀多——今天买明天砸、明天买后天砸，每天都套一批 | 稿 09:13–10:08 |
| 下跌中继 | 主跌中出现的分时反弹或日 K 尝试反弹；反弹后紧接着再出大阴线 | 稿 11:21–12:08 |
| 低位试错 | 亏钱效应**明显减缓、不再连续**；节奏变成涨一天跌一天 | 稿 12:14–12:33 |
| 首次见底 | 指数进入反弹周期，首次反弹约 2~3 天；通常表现为跳空大跌 + 加速连阴 + 大阳线 | 稿 12:50–13:13、31:23–31:38 |
| 二次见底 | 对前底部的有效性判断：反弹上去后再把抛压砸出来，通常落在第一个底部上方一点或与之持平（双底/W 底，可轻微跌破后长下影拉回） | 稿 15:48–16:51 |
| 新高震荡 | 板块震到前高附近；核心逻辑是**释放前高的套牢盘**；节奏与低位试错相似但更宽更强 | 稿 17:38–18:19、20:33–20:46 |
| 主升 | 连续上涨、小阴连阳、快速向上进攻；调整**很少超过两天** | 稿 20:46–21:04 |
| 高位震荡初期 | 上涨速率明显变缓但无连续亏钱效应；节奏变为退二进三 / 退一进二 / 退三进四；板块勉强新高 | 稿 24:12–24:49 |
| 高位震荡后期 | 出现**明显箱体**；围绕箱体上下沿运行 | 稿 26:45–27:05 |
| 高位震荡转二波 | 再次跳空高开（性质等同"上涨中继"）突破平台 | 稿 27:06–27:19 |

- **关键分界：新高震荡 ≠ 高位震荡**。新高震荡释放的是前高套牢盘，高位震荡释放的是下方盈利盘（稿 23:52–24:12）。
- **底部是"打"出来的，不是"震"出来的**：必须向下砸出来才看得出底部；若每天十字星横盘"肯定不行"（稿 33:44–34:18）。
- **强弱切换的量化节奏**：亏钱效应减弱 → 赚钱效应增强，表现为由"跌一天涨一天"变成"跌一天涨两天""跌两天涨三天"（稿 16:57–17:29）。
- **二次见底买点的准确性**：越临近第一次底部，买点的准确性越强（稿 33:13–33:30）。

## 操作逻辑（选股·买点·卖点）

### 各阶段操作清单（UP 主给出的可执行动作）

| 阶段 | 操作动作 | 出处 |
|---|---|---|
| 主跌 | **快速、大幅度减仓**，把仓位快速降下来；**不做逆势抗跌品种**（抗跌是主跌期常见坑，最终结果往往是吃两个补跌大阴线）；等市场扛住、稳住再做 | 稿 10:16–11:19 |
| 下跌中继 | 割肉清空，再找下一个底部 | 稿 15:19–15:25 |
| 低位试错 | 拿先手（先手仓在启动日建）；次日做 T；"有赚就走"是重点 | 稿 12:28–12:33、15:14–15:19 |
| 首次见底 | 属于**左侧预判**，难以把握，作为低位试错的一部分处理 | 稿 12:50–13:12 |
| 二次见底 | 在前低有效性判断处做试错；只是试错，不一定成立 | 稿 33:30–33:43 |
| 新高震荡 | **挖掘主线**，把最强品种背下来，明确主线与共振品种，开始"适当聚焦"；第一根大阳线不卖，观察前高附近的持续性 | 稿 18:21–18:43、34:36–34:54 |
| 新高震荡→主升 | 觉得弱就在新高震荡阶段卖掉；觉得强就围绕核心品种**做 T** | 稿 34:47–35:02 |
| 主升 | **重仓捂股 + 聚焦主线**，适当放长持股周期，**不做分支** | 稿 21:08–21:22、23:08–23:21 |
| 高位震荡初期 | 可以继续拿；也可先卖后买做波段、做横盘的主动预判 | 稿 26:33–26:43 |
| 高位震荡后期 | **低买高卖、做波段、做区间**；低位敢买、高位敢卖 | 稿 28:19–28:57 |
| 转二波主升 | 突破平台要**敢追回来**，此后按主升思路持有 | 稿 29:01–29:20 |
| 转主跌 | 按最左边"主跌"处理（快速减仓） | 稿 29:23–29:31 |

### 选股
- 新高/主升阶段选**主线最强品种与共振品种**，而非分支（稿 18:21–18:43、23:17–23:21）。
- 主升期继续拿后排分支会进入"退二进二 / 退三进二 / 退三进四"这类更弱走势（稿 24:52–25:10）。

### 买点
- **左侧买点**：首次见底的大阳线日，属于"低位的左侧预判"（稿 13:05–13:12）。
- **先手买点**：低位试错的启动日（启动第一天/第二天）建仓（稿 06:48–06:56、15:14–15:18）。
- **试错买点**：二次见底处，"越临近第一次底部准确性越强"（稿 33:13–33:33）。
- **追买点**：高位震荡后期再次跳空突破平台时（稿 27:06–27:19、29:01–29:17）。
- **低吸买点**：高位震荡箱体低点（稿 28:19–28:44）。

### 卖点
- 高位震荡中反弹两三天到高位就**要敢卖**，不要等又跌两三天再后悔（稿 28:42–28:55）。
- 高位震荡后期出现**连续阴跌两三天**时，需警惕转主跌（稿 28:03–28:18、14:16–14:39）。
- 跌破箱体/跌破高位震荡区间即视为进入主跌（PCB 案例：7 月 6 日大阴线跌破）（稿 37:49–37:56）。

### 仓位
- UP 主自述的实操片段：上周四打**半仓**，周五早盘清空，尾盘再买回来；后续若反弹则以低位试错思路加仓、做 T（稿 14:26–14:56）。
- 高位震荡阶段"通过节奏**和仓位**进行滚动"（稿 12:03–12:07）。

## 关键规则与数字

- **多杀多定义**：今天买明天砸、明天买后天砸，"每一天都套"，构成持续性下跌（稿 09:30–09:45）。
- **98 天跌 40%**：锂电池 2021 年见顶后的主跌幅度（稿 03:07–03:12）。
- **首次反弹 2~3 天**：首次见底后的反弹时长经验值（稿 12:56、31:26）。
- **主升调整很少超过两天**（稿 21:04）。
- **主升利润量级**：低位节奏好赚 10–20 个点，主升做好一波 50 个点很正常；主升段"赚三五十个点非常正常"（稿 21:33–21:44、23:04–23:06）。
- **节奏规律**：低位试错 = 涨一天跌一天；赚钱效应酝酿 = 跌一天涨两天 / 跌两天涨三天；高位震荡 = 退一进二、退二进三、退三进四；走弱分支 = 退二进二、退三进二、退三进四（稿 15:11、17:09–17:17、24:28–24:38、25:02–25:07）。
- **高位震荡三大特点**：① 防转主跌；② 低买高卖做波段做区间；③ 转二波要敢追（稿 28:03–29:20）。
- **"底部是打出来的"**：向下砸出来才算底部确认；最多只调整一天（如 3 月 9 日长下影次日即上攻）；天天十字星横盘不算（稿 33:44–34:18）。
- **自我修正**：UP 主在 20:35 明确更正——那个位置叫"新高震荡"不叫"高位震荡"（稿 20:33–20:37）。
- **简化原则**：三个概念不必过度复杂化，只看亏钱效应是否连续（稿 14:59–15:13）。

## 案例分析

> 以下均为视频录制时点的历史个案（2026 年 3—7 月），用于说明方法，不构成对任何个股或板块的当前判断。

### 案例 1｜当周指数：主跌 → 下跌中继/低位试错的二选一（稿 00:00–15:27）
- 背景：上周五开盘大幅冲高"骗了个炮"后杀跌，UP 主在此前视频已提示"明天分歧要小心"。
- 判断框架：上周四（7/9）为潜在下跌中继；周五出大阴 → 下跌中继，周五反弹 → 低位试错；下周一科技再大幅反弹（两根红 K）→ 低位试错成立，一根大阴 → 下跌中继成立（稿 11:31–12:08、13:19–13:37）。
- 实操：周四打半仓，周五早盘清空、尾盘买回（稿 14:26–14:36）。

### 案例 2｜PCB 板块：一轮完整的情绪周期（稿 30:39–38:02）
| 时点 | 阶段判定 | 依据 |
|---|---|---|
| 3/17–3/23 | 主跌 | 连续下跌 |
| 3/22 | 首次见底 | 跳空大阴 + 加速连阴 + 大阳线，符合"首次反弹 2~3 天" |
| 3 月底—4 月初 | 低位试错 | 涨一天跌一天 / 涨两天跌一天，重心慢慢上移 |
| 3/9（前后） | 二次见底 | 长下影次日即上攻，属强底部确认 |
| 4/14 前 | 新高震荡 | 跳空高开进入进攻，观察前高附近持续性；中间出现"新高试盘"（长上影试抛压，属弱分歧） |
| 4/14 | 转主升 | 突破新高；首日涨、次日调整、第三日反包 |
| 4/22 | 高位震荡 | 进入震荡，做 T |
| 4/29 | 再创新高 | 震荡两三天后再转主升 |
| 7/1–7/3 | 高位震荡高/低点 | 高点卖、低点买；7/6 大阴线跌破 → 转主跌 |

- UP 主强调：最晚 4 月 14 日要确认 PCB 进入主升，此后按主升思路处理（稿 35:53–36:04）。
- 长持警告：若从 6 月底部起该板块真见顶，可能套 3/5/10 年、套 70%，大部分人拿不住（稿 38:07–38:27）。

### 案例 3｜CPU（存疑，或为 CPO）方向：主升与高位震荡（稿 22:26–27:05）
- 2026/4/8 跳空阳线启动，此后连阳小阴快速反包，"每一根阴线第二天都是涨的"，至 4/22 共十余天主升（稿 22:26–23:01）。
- 4/22 进入高位震荡初期：跌一两天、反弹一天、退一进二，维持初期反弹走势（稿 25:14–25:54）。
- 5/6 与 4/8 形态一致（新高启动 + 连阳），构成二波主升（稿 27:44–27:54）。

### 案例 4｜主跌后的新高方向（稿 18:45–20:17）
- 集成电路封测最先新高；集成电路制造、国产芯片/半导体设计已进入新高震荡；PCB 等仍在低位试错（稿 18:50–20:04）。

### 案例 5｜主升期切方向的反面教材（稿 23:23–23:41）
- UP 主自述两三个月里切换过四次锂电池、切换电力、切换金融，"还不如躺在主升中"，做主线震荡以外的方向很难赚钱。
